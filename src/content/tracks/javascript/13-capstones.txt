=== module Capstone projects

=== lesson js-capstone-app | Capstone 1: a habit tracker web app | 400
Time to build a complete application from start to finish, the way professional developers do: **plan, build in small tested steps, then polish**. You'll build a habit tracker that runs in the browser: users add habits, tick them off each day, see their streaks and weekly progress, and find everything still there when they come back.

## How a task like this is approached

1. **Clarify the requirements as user stories.** *"As a user, I can add a habit (like 'Read 20 minutes') so I can track it."* *"As a user, I tick a habit off for today, and can undo a mistake."* *"As a user, I see my current streak, so I'm motivated not to break it."* *"As a user, I see how many days this week I've done each habit compared with my goal."* *"As a user, my habits are still there tomorrow."*
2. **Separate the model from the page.** The rules (what a streak is, what counts as this week, which names are allowed) live in plain JavaScript classes with no DOM code at all, so they can be tested quickly and reused (a mobile app or a server could use the same model). The page only renders the model and turns clicks into method calls: the "render from state" pattern from Module 11.
3. **Decide the hard rules up front.** Days are `"YYYY-MM-DD"` strings in UTC (Module 12: they're unambiguous, compare correctly as text, and survive JSON). "Today" is **injected** rather than read from the clock inside the model, so tests are deterministic. Invalid input raises one domain error, `HabitError`.
4. **Build in vertical slices**, each fully working and tested before the next:
   - Step 1: the model (`Habit`, `Tracker`), tested in isolation;
   - Step 2: the user interface: rendering, a form and delegated events;
   - Step 3: persistence with `localStorage`, plus the weekly progress view.
5. **Refactor as you go**, keeping functions small and named after what they do.

Each step's starter contains a working solution to the previous steps, so you can always continue. By the end you'll have written a few hundred lines of real, tested JavaScript: a small but genuine product.

## The rules of a streak

Streaks need a precise definition, or every developer implements a different one:

- If the habit is done **today**, the streak counts consecutive done days going back from today.
- If it isn't done today yet but was done **yesterday**, the streak is still alive: count back from yesterday (the user still has today to keep it going).
- Otherwise the streak is 0.

Writing the rule down first, then turning each sentence into a test, is exactly how professionals avoid ambiguous requirements.

📚 **Go deeper:** MDN, "Client-side storage"; Martin Fowler, "Presentation Domain Data Layering" (martinfowler.com); *Eloquent JavaScript* (4th ed.), chapter 19, "Project: A Pixel Art Editor" (another state-driven app).

**Step 1: the model.** Write:

- `HabitError extends Error` (with `name` set to `"HabitError"`);
- a helper `addDays(day, n)` for `"YYYY-MM-DD"` strings (UTC);
- `class Habit`: `constructor(name, { goalPerWeek = 7 } = {})` trims the name and throws a `HabitError` if it's empty or longer than 40 characters, or if `goalPerWeek` isn't a whole number from 1 to 7. class HabitError extends Error {
  constructor(message) {
    super(message);
    this.name = "HabitError";
  }
}

function addDays(day, n) {
  const d = new Date(day + "T00:00:00Z");
  d.setUTCDate(d.getUTCDate() + n);
  return d.toISOString().slice(0, 10);
}

class Habit {
  #days = new Set();

  constructor(name, { goalPerWeek = 7 } = {}) {
    const clean = String(name ?? "").trim();
    if (!clean || clean.length > 40) throw new HabitError("A habit needs a name of 1 to 40 characters");
    if (!Number.isInteger(goalPerWeek) || goalPerWeek < 1 || goalPerWeek > 7) throw new HabitError("The weekly goal must be 1 to 7 days");
    this.name = clean;
    this.goalPerWeek = goalPerWeek;
  }

  check(day) {
    if (this.#days.has(day)) return false;
    this.#days.add(day);
    return true;
  }

  uncheck(day) {
    return this.#days.delete(day);
  }

  isDone(day) {
    return this.#days.has(day);
  }

  streak(today) {
    let day = this.isDone(today) ? today : addDays(today, -1);
    let count = 0;
    while (this.isDone(day)) {
      count++;
      day = addDays(day, -1);
    }
    return count;
  }

  doneThisWeek(today) {
    let count = 0;
    for (let i = 0; i < 7; i++) if (this.isDone(addDays(today, -i))) count++;
    return count;
  }

  toJSON() {
    return { name: this.name, goalPerWeek: this.goalPerWeek, days: [...this.#days].sort() };
  }

  static fromJSON({ name, goalPerWeek, days = [] }) {
    const habit = new Habit(name, { goalPerWeek });
    for (const day of days) habit.check(day);
    return habit;
  }
}

class Tracker {
  #habits = new Map();

  add(name, options) {
    const habit = new Habit(name, options);
    const key = habit.name.toLowerCase();
    if (this.#habits.has(key)) throw new HabitError(`You already track "${habit.name}"`);
    this.#habits.set(key, habit);
    return habit;
  }

  remove(name) {
    return this.#habits.delete(String(name).trim().toLowerCase());
  }

  get(name) {
    return this.#habits.get(String(name).trim().toLowerCase());
  }

  get habits() {
    return [...this.#habits.values()].sort((a, b) => a.name.localeCompare(b.name));
  }

  toJSON() {
    return this.habits.map((h) => h.toJSON());
  }

  static fromJSON(data) {
    const tracker = new Tracker();
    for (const item of data) {
      const habit = Habit.fromJSON(item);
      tracker.#habits.set(habit.name.toLowerCase(), habit);
    }
    return tracker;
  }
}

    <script>
      const today = () => window.TODAY ?? new Date().toISOString().slice(0, 10);
      const tracker = new Tracker();

      function habitItem(habit) {
        const li = document.createElement("li");
        li.dataset.name = habit.name;
        const name = document.createElement("span");
        name.className = "name";
        name.textContent = habit.name;
        const streak = document.createElement("span");
        streak.className = "streak";
        streak.textContent = `🔥 ${habit.streak(today())}`;
        const check = document.createElement("button");
        check.className = "check";
        check.textContent = habit.isDone(today()) ? "Undo" : "Done today";
        const remove = document.createElement("button");
        remove.className = "remove";
        remove.textContent = "Remove";
        li.append(name, " ", streak, " ", check, " ", remove);
        return li;
      }

      function render() {
        const habits = tracker.habits;
        document.querySelector("#habits").replaceChildren(...habits.map(habitItem));
        const done = habits.filter((h) => h.isDone(today())).length;
        document.querySelector("#summary").textContent = `${done} of ${habits.length} done today`;
      }

      document.querySelector("#new-habit").addEventListener("submit", (event) => {
        event.preventDefault();
        const form = event.target;
        try {
          tracker.add(form.elements.name.value, { goalPerWeek: Number(form.elements.goal.value) });
          document.querySelector("#error").textContent = "";
          form.reset();
        } catch (error) {
          if (!(error instanceof HabitError)) throw error;
          document.querySelector("#error").textContent = error.message;
        }
        render();
      });

      document.querySelector("#habits").addEventListener("click", (event) => {
        const li = event.target.closest("li");
        if (!li) return;
        const habit = tracker.get(li.dataset.name);
        if (event.target.closest(".check")) {
          if (habit.isDone(today())) habit.uncheck(today());
          else habit.check(today());
        } else if (event.target.closest(".remove")) {
          tracker.remove(habit.name);
        } else {
          return;
        }
        render();
      });

      render();
    </script>
  </body>
</html>

**Step 3: persistence and weekly progress.**

- Save the tracker to `localStorage` under the key `"habits"` (as JSON) after **every** change, with a `save()` function. === lesson js-capstone-cli | Capstone 2: a command-line task manager | 400
Your second capstone runs in **Node.js**: a command-line to-do manager, the kind of small tool developers write for themselves all the time. It's used like this:

```
node main.js add "Write the report" --due=2026-10-20 --urgent
node main.js list
node main.js done 1
node main.js remove 2
node main.js list --all
```

Tasks are saved in a JSON file between runs, so the program must read and write files safely, handle bad input with clear messages and **exit codes**, and keep its logic testable.

## The design

Three modules, each with one job:

1. **`args.js`**: turns the raw `process.argv` array into a structured command: `{ command: "add", positional: ["Write the report"], flags: { due: "2026-10-20", urgent: true } }`. Parsing input is a separate concern from acting on it.
2. **`store.js`**: a `TaskStore` class that loads tasks from a JSON file, changes them, and saves them back. It knows nothing about the command line.
3. **`cli.js`**: `run(argv, store)` connects the two: it parses, calls the store, and **returns** the lines to print and an exit code instead of printing directly. That one decision makes the whole CLI testable without capturing the console. `main.js` is then three lines: run, print, set `process.exitCode`.

This "functional core, imperative shell" shape (pure logic inside, input/output at the edges) is how professionals keep command-line tools, servers and scripts testable.

## Exit codes and error messages

Command-line tools communicate with exit codes: 0 means success, anything else failure (scripts, `&&` chains and CI rely on it). By convention: `1` for an operation that failed (no task with that id), `2` for incorrect usage (unknown command, missing argument). Error messages go to the user in plain words and suggest what to do: `Unknown command "lsit". Try: add, list, done, remove, help`.

📚 **Go deeper:** Node.js documentation, `process.argv`, `process.exitCode` and `util.parseArgs`; the Command Line Interface Guidelines (clig.dev); Gary Bernhardt, "Functional Core, Imperative Shell".

// file: args.js
export function parseArgs(argv) {
  const result = { command: null, positional: [], flags: {} };
  let onlyPositional = false;
  for (const arg of argv) {
    if (!onlyPositional && arg === "--") {
      onlyPositional = true;
    } else if (!onlyPositional && arg.startsWith("--")) {
      const body = arg.slice(2);
      const eq = body.indexOf("=");
      if (eq >= 0) result.flags[body.slice(0, eq)] = body.slice(eq + 1);
      else if (body.startsWith("no-")) result.flags[body.slice(3)] = false;
      else result.flags[body] = true;
    } else if (!onlyPositional && /^-[A-Za-z]+$/.test(arg)) {
      for (const letter of arg.slice(1)) result.flags[letter] = true;
    } else if (result.command === null) {
      result.command = arg;
    } else {
      result.positional.push(arg);
    }
  }
  return result;
}

// file: store.js
import { readFileSync, writeFileSync } from "node:fs";

export class TaskError extends Error {
  constructor(message) {
    super(message);
    this.name = "TaskError";
  }
}

export class TaskStore {
  #tasks = [];

  constructor(path) {
    this.path = path;
  }

  load() {
    let text;
    try {
      text = readFileSync(this.path, "utf8");
    } catch (error) {
      if (error.code === "ENOENT") {
        this.#tasks = [];
        return this;
      }
      throw error;
    }
    try {
      this.#tasks = JSON.parse(text);
    } catch {
      throw new TaskError(`Corrupt task file: ${this.path}`);
    }
    return this;
  }

  save() {
    writeFileSync(this.path, JSON.stringify(this.#tasks, null, 2));
  }

  add(title, { due = null, urgent = false } = {}) {
    const clean = String(title ?? "").trim();
    if (!clean) throw new TaskError("A task needs a title");
    if (due !== null && !/^\d{4}-\d{2}-\d{2}$/.test(due)) throw new TaskError(`Due dates look like 2026-10-20, not "${due}"`);
    const id = this.#tasks.reduce((max, t) => Math.max(max, t.id), 0) + 1;
    const task = { id, title: clean, due, urgent: Boolean(urgent), done: false };
    this.#tasks.push(task);
    return task;
  }

  #find(id) {
    const task = this.#tasks.find((t) => t.id === Number(id));
    if (!task) throw new TaskError(`No task with id ${id}`);
    return task;
  }

  done(id) {
    const task = this.#find(id);
    task.done = true;
    return task;
  }

  remove(id) {
    const task = this.#find(id);
    this.#tasks = this.#tasks.filter((t) => t !== task);
    return task;
  }

  list({ all = false } = {}) {
    return this.#tasks
      .filter((t) => all || !t.done)
      .toSorted((a, b) => Number(b.urgent) - Number(a.urgent) || (a.due ?? "9999").localeCompare(b.due ?? "9999") || a.id - b.id);
  }
}

// file: args.js
export function parseArgs(argv) {
  const result = { command: null, positional: [], flags: {} };
  let onlyPositional = false;
  for (const arg of argv) {
    if (!onlyPositional && arg === "--") onlyPositional = true;
    else if (!onlyPositional && arg.startsWith("--")) {
      const body = arg.slice(2);
      const eq = body.indexOf("=");
      if (eq >= 0) result.flags[body.slice(0, eq)] = body.slice(eq + 1);
      else if (body.startsWith("no-")) result.flags[body.slice(3)] = false;
      else result.flags[body] = true;
    } else if (!onlyPositional && /^-[A-Za-z]+$/.test(arg)) {
      for (const letter of arg.slice(1)) result.flags[letter] = true;
    } else if (result.command === null) result.command = arg;
    else result.positional.push(arg);
  }
  return result;
}

=== lesson js-capstone-interpreter | Capstone 3: build a tiny programming language | 450
You've written thousands of lines of JavaScript; now you'll build a **programming language** of your own, with JavaScript. It's called **Calc**: a calculator language with variables, functions, comparisons and recursion:

```
let r = 2
pi * r ^ 2
fn square(n) = n * n
fn fact(n) = if(n < 2, 1, n * fact(n - 1))
fact(10)
```

This is a classic project for a reason. Every language you'll ever use (JavaScript in V8, Python, SQL in a database, even spreadsheet formulas) runs through the same three stages, and building them yourself demystifies them for good:

1. **Tokenizer** (lexer): turns text into **tokens**, the words of the language: numbers, names, operators. `let r = 2` becomes `keyword:let`, `name:r`, `op:=`, `number:2`.
2. **Parser**: turns the token list into a tree that shows the program's structure, an **abstract syntax tree** (AST). `1 + 2 * 3` becomes "add 1 to (multiply 2 by 3)", because `*` binds tighter than `+`.
3. **Interpreter** (evaluator): walks the tree and computes values, keeping variables and functions in an **environment**.

Then you'll wrap it in a **REPL** (read-eval-print loop) in Node, like the `node` prompt itself.

## The grammar

A language is defined by its **grammar**. Calc's, from the loosest-binding rule to the tightest:

```
program    := statement (";" or new line) statement ...
statement  := "let" NAME "=" expr  |  "fn" NAME "(" NAME, ... ")" "=" expr  |  expr
expr       := sum ( ("<" | ">" | "<=" | ">=" | "==" | "!=") sum )?
sum        := term ( ("+" | "-") term )*
term       := unary ( ("*" | "/" | "%") unary )*
unary      := "-" unary  |  power
power      := value ( "^" unary )?
value      := NUMBER  |  NAME  |  NAME "(" expr, ... ")"  |  "(" expr ")"
```

Each rule becomes one function in a **recursive descent parser**: `sum()` calls `term()`, which calls `unary()`, and so on down; `value()` calls `expr()` again for parentheses, which is where the recursion comes from. Precedence falls out of the structure: because `sum` is built from `term`s, multiplication is always grouped first.

Two details worth noticing:

- `^` is **right-associative** (`2 ^ 3 ^ 2` is `2 ^ 9`), so `power` parses its right side with `unary()` again instead of looping. And `-2 ^ 2` is `-(2 ^ 2)` = -4, as in maths.
- `if(cond, a, b)` looks like a function call, but it's a **special form**: only the chosen branch may be evaluated. Otherwise `fact` would recurse forever and `if(0, 1 / 0, 7)` would fail. Eloquent JavaScript's "Egg" language uses the same trick.

## Design notes

- Errors are one class, `CalcError`, that knows the **line and column** where things went wrong: good error messages are what separate a toy language from a usable one.
- The AST is plain objects (`{ type: "binary", op: "+", left, right }`), easy to print and test.
- An **environment** maps names to values and has a `parent` link. Function calls get a new environment whose parent is the one where the function was defined: the **lexical scope** and closures from Module 5, now implemented by you.
- Infinite recursion must not crash the host: count call depth and stop with a clear error.

The four steps are four modules: `lexer.js`, `parser.js`, `interpreter.js` and the REPL in `main.js`. Each step's starter contains the previous steps' solutions.

- numbers like `42` or `3.5` → type `"number"`, value a **number**;
- names (`[A-Za-z_]` then letters, digits or `_`) → `"name"`, except `let` and `fn`, which are `"keyword"`;

// file: lexer.js
export class CalcError extends Error {
  constructor(message, line = null, col = null) {
    super(line === null ? message : `${message} (line ${line}, column ${col})`);
    this.name = "CalcError";
    this.line = line;
    this.col = col;
  }
}

const KEYWORDS = new Set(["let", "fn"]);
const TWO_CHAR = ["<=", ">=", "==", "!="];
const ONE_CHAR = "+-*/%^=(),;<>";

export function tokenize(source) {
  const tokens = [];
  let i = 0;
  let line = 1;
  let col = 1;
  const push = (type, value, length) => {
    tokens.push({ type, value, line, col });
    i += length;
    col += length;
  };
  while (i < source.length) {
    const ch = source[i];
    if (ch === "\n") {
      tokens.push({ type: "op", value: ";", line, col });
      i++;
      line++;
      col = 1;
      continue;
    }
    if (ch === " " || ch === "\t" || ch === "\r") {
      i++;
      col++;
      continue;
    }
    if (ch === "#") {
      while (i < source.length && source[i] !== "\n") {
        i++;
        col++;
      }
      continue;
    }
    const rest = source.slice(i);
    const number = rest.match(/^\d+(\.\d+)?/);
    if (number) {
      push("number", Number(number[0]), number[0].length);
      continue;
    }
    const word = rest.match(/^[A-Za-z_]\w*/);
    if (word) {
      push(KEYWORDS.has(word[0]) ? "keyword" : "name", word[0], word[0].length);
      continue;
    }
    if (TWO_CHAR.includes(rest.slice(0, 2))) {
      push("op", rest.slice(0, 2), 2);
      continue;
    }
    if (ONE_CHAR.includes(ch)) {
      push("op", ch, 1);
      continue;
    }
    throw new CalcError(`Unexpected character "${ch}"`, line, col);
  }
  return tokens;
}

// file: parser.js
import { CalcError } from "./lexer.js";

const COMPARE = ["<", ">", "<=", ">=", "==", "!="];

export function parse(tokens) {
  let pos = 0;
  const peek = () => tokens[pos];
  const isOp = (value) => peek()?.type === "op" && peek().value === value;
  const fail = (what) => {
    const token = peek();
    if (!token) throw new CalcError(`Expected ${what} but reached the end`);
    throw new CalcError(`Expected ${what} but found "${token.value}"`, token.line, token.col);
  };
  const expectOp = (value) => {
    if (!isOp(value)) fail(`"${value}"`);
    pos++;
  };
  const expectName = () => {
    if (peek()?.type !== "name") fail("a name");
    return tokens[pos++].value;
  };

  function list(item) {
    const items = [];
    if (!isOp(")")) {
      items.push(item());
      while (isOp(",")) {
        pos++;
        items.push(item());
      }
    }
    expectOp(")");
    return items;
  }

  function statement() {
    const token = peek();
    if (token.type === "keyword" && token.value === "let") {
      pos++;
      const name = expectName();
      expectOp("=");
      return { type: "let", name, value: expr() };
    }
    if (token.type === "keyword" && token.value === "fn") {
      pos++;
      const name = expectName();
      expectOp("(");
      const params = list(expectName);
      expectOp("=");
      return { type: "fn", name, params, body: expr() };
    }
    return { type: "expr", expr: expr() };
  }

  function expr() {
    const left = sum();
    if (peek()?.type === "op" && COMPARE.includes(peek().value)) {
      const op = tokens[pos++].value;
      return { type: "binary", op, left, right: sum() };
    }
    return left;
  }

  function sum() {
    let left = term();
    while (isOp("+") || isOp("-")) {
      const op = tokens[pos++].value;
      left = { type: "binary", op, left, right: term() };
    }
    return left;
  }

  function term() {
    let left = unary();
    while (isOp("*") || isOp("/") || isOp("%")) {
      const op = tokens[pos++].value;
      left = { type: "binary", op, left, right: unary() };
    }
    return left;
  }

  function unary() {
    if (isOp("-")) {
      pos++;
      return { type: "unary", op: "-", arg: unary() };
    }
    return power();
  }

  function power() {
    const base = value();
    if (isOp("^")) {
      pos++;
      return { type: "binary", op: "^", left: base, right: unary() };
    }
    return base;
  }

  function value() {
    const token = peek();
    if (token?.type === "number") {
      pos++;
      return { type: "num", value: token.value };
    }
    if (token?.type === "name") {
      pos++;
      if (isOp("(")) {
        pos++;
        return { type: "call", name: token.value, args: list(expr) };
      }
      return { type: "var", name: token.value };
    }
    if (isOp("(")) {
      pos++;
      const inner = expr();
      expectOp(")");
      return inner;
    }
    fail("a value");
  }

  const body = [];
  while (pos < tokens.length) {
    if (isOp(";")) {
      pos++;
      continue;
    }
    body.push(statement());
    if (pos < tokens.length && !isOp(";")) fail("the end of the statement");
  }
  return { type: "program", body };
}

// file: interpreter.js
import { CalcError } from "./lexer.js";

const BUILTINS = { sqrt: Math.sqrt, abs: Math.abs, round: Math.round, floor: Math.floor, max: Math.max, min: Math.min };
const MAX_DEPTH = 500;
let depth = 0;

export function createEnvironment() {
  return { vars: new Map([["pi", Math.PI]]), fns: new Map(), parent: null };
}

function lookup(env, name) {
  for (let e = env; e; e = e.parent) if (e.vars.has(name)) return e.vars.get(name);
  throw new CalcError(`Unknown variable "${name}"`);
}

function findFunction(env, name) {
  for (let e = env; e; e = e.parent) if (e.fns.has(name)) return e.fns.get(name);
  return null;
}

function binary(op, a, b) {
  switch (op) {
    case "+": return a + b;
    case "-": return a - b;
    case "*": return a * b;
    case "/":
    case "%":
      if (b === 0) throw new CalcError("Division by zero");
      return op === "/" ? a / b : a % b;
    case "^": return a ** b;
    case "<": return a < b ? 1 : 0;
    case ">": return a > b ? 1 : 0;
    case "<=": return a <= b ? 1 : 0;
    case ">=": return a >= b ? 1 : 0;
    case "==": return a === b ? 1 : 0;
    case "!=": return a !== b ? 1 : 0;
    default: throw new CalcError(`Unknown operator ${op}`);
  }
}

function call(node, env) {
  if (node.name === "if") {
    if (node.args.length !== 3) throw new CalcError(`if expects 3 arguments, got ${node.args.length}`);
    return evaluate(node.args[0], env) !== 0 ? evaluate(node.args[1], env) : evaluate(node.args[2], env);
  }
  const fn = findFunction(env, node.name);
  if (fn) {
    const n = fn.params.length;
    if (node.args.length !== n) throw new CalcError(`${node.name} expects ${n} argument${n === 1 ? "" : "s"}, got ${node.args.length}`);
    const scope = { vars: new Map(fn.params.map((p, i) => [p, evaluate(node.args[i], env)])), fns: new Map(), parent: fn.closure };
    if (++depth > MAX_DEPTH) {
      depth = 0;
      throw new CalcError(`Too much recursion (more than ${MAX_DEPTH} nested calls)`);
    }
    try {
      return evaluate(fn.body, scope);
    } finally {
      depth = Math.max(0, depth - 1);
    }
  }
  if (Object.hasOwn(BUILTINS, node.name)) return BUILTINS[node.name](...node.args.map((a) => evaluate(a, env)));
  throw new CalcError(`Unknown function "${node.name}"`);
}

function evaluate(node, env) {
  switch (node.type) {
    case "num": return node.value;
    case "var": return lookup(env, node.name);
    case "unary": return -evaluate(node.arg, env);
    case "binary": return binary(node.op, evaluate(node.left, env), evaluate(node.right, env));
    case "call": return call(node, env);
    default: throw new CalcError(`Unknown node ${node.type}`);
  }
}

export function run(program, env = createEnvironment()) {
  const results = [];
  for (const statement of program.body) {
    if (statement.type === "let") {
      const value = evaluate(statement.value, env);
      env.vars.set(statement.name, value);
      results.push({ type: "let", name: statement.name, value });
    } else if (statement.type === "fn") {
      env.fns.set(statement.name, { params: statement.params, body: statement.body, closure: env });
      results.push({ type: "fn", name: statement.name, params: statement.params });
    } else {
      results.push({ type: "value", value: evaluate(statement.expr, env) });
    }
  }
  return results;
}

    const token = peek();

    fail("a value");

// file: lexer.js
export class CalcError extends Error {
  constructor(message, line = null, col = null) {
    super(line === null ? message : `${message} (line ${line}, column ${col})`);
    this.name = "CalcError";
    this.line = line;
    this.col = col;
  }
}
const KEYWORDS = new Set(["let", "fn"]);
const TWO_CHAR = ["<=", ">=", "==", "!="];
const ONE_CHAR = "+-*/%^=(),;<>";
export function tokenize(source) {
  const tokens = [];
  let i = 0, line = 1, col = 1;
  const push = (type, value, length) => { tokens.push({ type, value, line, col }); i += length; col += length; };
  while (i < source.length) {
    const ch = source[i];
    if (ch === "\n") { tokens.push({ type: "op", value: ";", line, col }); i++; line++; col = 1; continue; }
    if (ch === " " || ch === "\t" || ch === "\r") { i++; col++; continue; }
    if (ch === "#") { while (i < source.length && source[i] !== "\n") { i++; col++; } continue; }
    const rest = source.slice(i);
    const number = rest.match(/^\d+(\.\d+)?/);
    if (number) { push("number", Number(number[0]), number[0].length); continue; }
    const word = rest.match(/^[A-Za-z_]\w*/);
    if (word) { push(KEYWORDS.has(word[0]) ? "keyword" : "name", word[0], word[0].length); continue; }
    if (TWO_CHAR.includes(rest.slice(0, 2))) { push("op", rest.slice(0, 2), 2); continue; }
    if (ONE_CHAR.includes(ch)) { push("op", ch, 1); continue; }
    throw new CalcError(`Unexpected character "${ch}"`, line, col);
  }
  return tokens;
}

import { CalcError } from "./lexer.js";
const COMPARE = ["<", ">", "<=", ">=", "==", "!="];
export function parse(tokens) {
  let pos = 0;
  const peek = () => tokens[pos];
  const isOp = (value) => peek()?.type === "op" && peek().value === value;
  const fail = (what) => {
    const token = peek();
    if (!token) throw new CalcError(`Expected ${what} but reached the end`);
    throw new CalcError(`Expected ${what} but found "${token.value}"`, token.line, token.col);
  };
  const expectOp = (value) => { if (!isOp(value)) fail(`"${value}"`); pos++; };
  const expectName = () => { if (peek()?.type !== "name") fail("a name"); return tokens[pos++].value; };
  function list(item) {
    const items = [];
    if (!isOp(")")) { items.push(item()); while (isOp(",")) { pos++; items.push(item()); } }
    expectOp(")");
    return items;
  }
  function statement() {
    const token = peek();
    if (token.type === "keyword" && token.value === "let") { pos++; const name = expectName(); expectOp("="); return { type: "let", name, value: expr() }; }
    if (token.type === "keyword" && token.value === "fn") { pos++; const name = expectName(); expectOp("("); const params = list(expectName); expectOp("="); return { type: "fn", name, params, body: expr() }; }
    return { type: "expr", expr: expr() };
  }
  function expr() {
    const left = sum();
    if (peek()?.type === "op" && COMPARE.includes(peek().value)) { const op = tokens[pos++].value; return { type: "binary", op, left, right: sum() }; }
    return left;
  }
  function sum() { let left = term(); while (isOp("+") || isOp("-")) { const op = tokens[pos++].value; left = { type: "binary", op, left, right: term() }; } return left; }
  function term() { let left = unary(); while (isOp("*") || isOp("/") || isOp("%")) { const op = tokens[pos++].value; left = { type: "binary", op, left, right: unary() }; } return left; }
  function unary() { if (isOp("-")) { pos++; return { type: "unary", op: "-", arg: unary() }; } return power(); }
  function power() { const base = value(); if (isOp("^")) { pos++; return { type: "binary", op: "^", left: base, right: unary() }; } return base; }
  function value() {
    const token = peek();
    if (token?.type === "number") { pos++; return { type: "num", value: token.value }; }
    if (token?.type === "name") { pos++; if (isOp("(")) { pos++; return { type: "call", name: token.value, args: list(expr) }; } return { type: "var", name: token.value }; }
    if (isOp("(")) { pos++; const inner = expr(); expectOp(")"); return inner; }
    fail("a value");
  }
  const body = [];
  while (pos < tokens.length) {
    if (isOp(";")) { pos++; continue; }
    body.push(statement());
    if (pos < tokens.length && !isOp(";")) fail("the end of the statement");
  }
  return { type: "program", body };
}

In the real world, nobody hands you a starter with the functions already named and hints at every step. You get a **specification**: a description of what the software must do, often incomplete, and you design and build it yourself. This final capstone works exactly like that. Read the spec, decide on your design, write your own tests for the rules, and submit. Hidden checks then test every rule in the spec, including the edge cases.

## The product: a link shortener

Your company wants an internal link shortener (like bit.ly). Implement it as a JavaScript module: no user interface, just the core service that a web server would call.

### The spec

**Errors.** All errors are instances of `ShortenerError` (a subclass of `Error`), with these subclasses, each with its `name` set to its class name: `InvalidUrlError`, `ConflictError`, `NotFoundError`, `ExpiredError`, `PermissionError`, `RateLimitError`.

**`new LinkShortener({ now, random, codeLength })`**, all options optional:

- `now`: a function returning the current time in milliseconds (default `Date.now`);
- `random`: a function returning a number in [0, 1) (default `Math.random`);
- `codeLength`: the length of generated codes (default 6).

**`shorten(url, { owner, custom, ttlDays })`** creates a short link and returns `{ code, url, owner, createdAt, expiresAt }`:

1. `url` must be a valid absolute URL (use `new URL(url)`) with the protocol `http:` or `https:`; otherwise throw `InvalidUrlError`. Store the URL exactly as given.
2. `owner` is required (a non-empty string); otherwise throw `InvalidUrlError`.
3. If `custom` is given, it's the code: 3 to 20 characters, only letters, digits, `-` and `_` (otherwise `InvalidUrlError`), and it must not be taken by any link, expired or not (otherwise `ConflictError`). Codes are case-sensitive.
4. Otherwise, generate a code of `codeLength` characters, each chosen as `ALPHABET[Math.floor(random() * 62)]` with `ALPHABET = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz"`. If the code is already taken, generate another.
5. If the same owner already shortened the same URL (without a custom code) and that link hasn't expired, return the **existing** link instead of creating a new one (without counting towards the rate limit).
6. `ttlDays` (optional, a positive number) sets `expiresAt` to `createdAt + ttlDays × 86,400,000`; without it, `expiresAt` is `null`.
7. Rate limit: an owner may create at most 5 links in any 60-second window (links created at times `t` with `now - t < 60000`); a sixth throws `RateLimitError`.

**`resolve(code)`** returns the link's URL and counts a visit (with its time). An unknown code throws `NotFoundError`; a link whose `expiresAt` is not null and is `<= now()` throws `ExpiredError`.

**`stats(code)`** returns `{ visits, lastVisitAt }` (`lastVisitAt` is `null` before the first visit); unknown codes throw `NotFoundError`.

**`linksBy(owner)`** returns that owner's codes, oldest first.

**`delete(code, owner)`** deletes a link; unknown code: `NotFoundError`; a different owner: `PermissionError`. A deleted code can be used again as a custom code.

## How to approach it

1. **Read the whole spec twice** and list every rule; each becomes at least one test.
2. **Design**: what state does the class need? (Probably a `Map` from code to link, plus something per owner for the rate limit.)
3. **Write your own tests** with `test()` and `assert` for the tricky rules (rate limit windows, expiry at exactly `expiresAt`, idempotent shortening) using a **fake clock**: `let t = 0; const s = new LinkShortener({ now: () => t });` then move `t` forward.
4. Build it in small steps, running your tests after each.

There's no starter code beyond an empty file: the design is yours.

class ShortenerError extends Error {
  constructor(message) {
    super(message);
    this.name = this.constructor.name;
  }
}
class InvalidUrlError extends ShortenerError {}
class ConflictError extends ShortenerError {}
class NotFoundError extends ShortenerError {}
class ExpiredError extends ShortenerError {}
class PermissionError extends ShortenerError {}
class RateLimitError extends ShortenerError {}

const ALPHABET = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz";
const DAY = 86_400_000;

class LinkShortener {
  #links = new Map();
  #created = new Map();

  constructor({ now = Date.now, random = Math.random, codeLength = 6 } = {}) {
    this.now = now;
    this.random = random;
    this.codeLength = codeLength;
  }

  #validUrl(url) {
    try {
      const parsed = new URL(url);
      return parsed.protocol === "http:" || parsed.protocol === "https:";
    } catch {
      return false;
    }
  }

  #isExpired(link, at) {
    return link.expiresAt !== null && link.expiresAt <= at;
  }

  #newCode() {
    let code;
    do {
      code = "";
      for (let i = 0; i < this.codeLength; i++) code += ALPHABET[Math.floor(this.random() * 62)];
    } while (this.#links.has(code));
    return code;
  }

  #public(link) {
    const { code, url, owner, createdAt, expiresAt } = link;
    return { code, url, owner, createdAt, expiresAt };
  }

  #get(code) {
    const link = this.#links.get(code);
    if (!link) throw new NotFoundError(`No link with code ${code}`);
    return link;
  }

  shorten(url, { owner, custom, ttlDays } = {}) {
    if (typeof url !== "string" || !this.#validUrl(url)) throw new InvalidUrlError(`Not a valid http(s) URL: ${url}`);
    if (typeof owner !== "string" || owner.trim() === "") throw new InvalidUrlError("An owner is required");
    const at = this.now();
    if (custom !== undefined) {
      if (typeof custom !== "string" || !/^[A-Za-z0-9_-]{3,20}$/.test(custom)) throw new InvalidUrlError(`Invalid custom code: ${custom}`);
      if (this.#links.has(custom)) throw new ConflictError(`The code ${custom} is taken`);
    } else {
      for (const link of this.#links.values()) {
        if (link.owner === owner && link.url === url && !link.custom && !this.#isExpired(link, at)) return this.#public(link);
      }
    }
    const recent = (this.#created.get(owner) ?? []).filter((t) => at - t < 60_000);
    if (recent.length >= 5) throw new RateLimitError(`${owner} has created too many links; try again in a minute`);
    if (ttlDays !== undefined && !(typeof ttlDays === "number" && ttlDays > 0)) throw new InvalidUrlError("ttlDays must be a positive number");
    const code = custom ?? this.#newCode();
    const link = { code, url, owner, createdAt: at, expiresAt: ttlDays ? at + ttlDays * DAY : null, custom: custom !== undefined, visits: 0, lastVisitAt: null };
    this.#links.set(code, link);
    this.#created.set(owner, [...recent, at]);
    return this.#public(link);
  }

  resolve(code) {
    const link = this.#get(code);
    const at = this.now();
    if (this.#isExpired(link, at)) throw new ExpiredError(`The link ${code} has expired`);
    link.visits++;
    link.lastVisitAt = at;
    return link.url;
  }

  stats(code) {
    const link = this.#get(code);
    return { visits: link.visits, lastVisitAt: link.lastVisitAt };
  }

  linksBy(owner) {
    return [...this.#links.values()].filter((l) => l.owner === owner).sort((a, b) => a.createdAt - b.createdAt).map((l) => l.code);
  }

  delete(code, owner) {
    const link = this.#get(code);
    if (link.owner !== owner) throw new PermissionError(`Only ${link.owner} can delete ${code}`);
    this.#links.delete(code);
  }
}

--- cards
Specification :: A description of what software must do. Turn each rule into a test before building.
Idempotent operation :: Repeating it gives the same result without extra effect (shortening the same URL twice).
Sliding window rate limit :: Count actions in the last N seconds (now - t < N), not per fixed minute.
Fake clock / fake random :: Inject now() and random() so time-based and random behaviour can be tested exactly.

=== lesson js-whats-next | What's next after JavaScript | 50
## You've learned JavaScript

Look back at Module 1: `console.log("Hello, World!")`. Since then you've learned values and types, decisions and loops, functions and closures, arrays, objects, Maps and Sets, errors and testing, classes, prototypes, inheritance and design patterns, iterators and generators, asynchronous code and web APIs, modules, Node.js, the DOM, forms, canvas, regular expressions, dates, security, TypeScript and the professional toolchain, and you've built a web app, a command-line tool and a programming language. That's the foundation professional JavaScript developers work on every day.

## Where to go from here

- **TypeScript**: the natural next step, and DevQuest's next language course. Almost every professional JavaScript job uses it.
- **A front-end framework**: React is the most requested in job adverts; Vue and Svelte are friendlier to start with. All of them build on the DOM, events, state and rendering ideas you already know.
- **The back end**: build an HTTP API with Node.js and Express or Fastify, talking to a database (the DevQuest SQL and PostgreSQL tracks).
- **Full stack**: Next.js (React) or SvelteKit put front and back end in one project.
- **Computer science**: the Data Structures & Algorithms track makes you faster at solving problems, and is what technical interviews test.
- **Career paths**: the Frontend, Backend and Full-Stack paths in DevQuest put these steps in order, with projects.

## Keep your skills alive

- **Build things you'd use yourself.** A personal project teaches more than ten tutorials, because you hit real problems.
- **Read other people's code.** Pick a small, popular npm package and read its source and tests.
- **Practise a little every day**: Code Dojo challenges, the Review tab's flashcards and drills.
- **Read the docs.** MDN for the language and the web platform, nodejs.org for Node. Getting comfortable with reference documentation is what makes you independent.
- **Share your work**: put projects on GitHub with a README and tests. That's your portfolio.
