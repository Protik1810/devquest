## Numbers

Go's numeric types say exactly how much memory they use:

| Type | Holds |
|---|---|
| `int` | whole numbers; 64 bits on modern computers (about ±9.2 × 10¹⁸). **Use it by default.** |
| `int8`, `int16`, `int32`, `int64` | signed integers of a fixed size |
| `uint`, `uint8` … `uint64` | unsigned (0 and up); `byte` is another name for `uint8` |
| `float64` | decimal numbers with about 15–16 significant digits. **The default for decimals.** |
| `float32` | less precise; used for graphics and big arrays |
| `complex128` | complex numbers (`3 + 4i`), for science and signal processing |

```go
package main

import (
	"fmt"
	"math"
)

func main() {
	var small int8 = 127
	small++ // integers wrap around silently when they overflow
	fmt.Println("int8 after 127:", small)
	fmt.Println("largest int64:", math.MaxInt64)

	population := 8_100_000_000 // underscores make big numbers readable
	hex, binary := 0xFF, 0b1010
	fmt.Println(population, hex, binary)

	x, y := 0.1, 0.2
	fmt.Println(x + y, 0.1+0.2)              // float64 is a binary approximation; constants are exact
	fmt.Println(math.Sqrt(2), math.Pi)       // the math package
	fmt.Println(math.Inf(1), -math.Inf(1), math.NaN())

	c := complex(3, 4)
	fmt.Println(c, real(c), imag(c))
}
```

Floating-point numbers can't represent most decimals exactly: with variables, `x + y` prints `0.30000000000000004`. The constant expression `0.1+0.2` prints `0.3` because the compiler computes constants exactly before converting them. For **money**, store whole cents in an `int64` (or use a decimal library such as `shopspring/decimal`).

## Booleans and strings

`bool` is `true` or `false`; Go never treats numbers as booleans (`if 1 {}` doesn't compile). `string` holds immutable text; the next lesson but one covers it in depth.

## Conversions

Go has **no automatic conversions** between types, not even from `int` to `float64`. You convert with the type's name, `T(value)`:

```go
package main

import (
	"fmt"
	"strconv"
)

func main() {
	items := 7
	people := 2
	fmt.Println(items / people)                   // 3: integer division
	fmt.Println(float64(items) / float64(people)) // 3.5
	price := 9.99
	fmt.Println(int(price), int(-price)) // 9 -9: truncates toward zero
	// int(9.99) with a constant doesn't compile: constants must convert exactly

	// numbers <-> text: the strconv package
	s := strconv.Itoa(42) + "!"
	n, err := strconv.Atoi("123")
	fmt.Println(s, n+1, err)
	_, err = strconv.Atoi("12a")
	fmt.Println(err)
	f, _ := strconv.ParseFloat("2.75", 64)
	fmt.Println(f * 2)
	fmt.Println(strconv.FormatFloat(1.0/3, 'f', 3, 64))
}
```

- `string(65)` does **not** give `"65"`: it's the character with code 65, `"A"` (and `go vet` warns). Use `strconv.Itoa`.
- Parsing can fail, so `strconv.Atoi` returns **two values**: the number and an `error` (`nil` when it worked). You'll see this pattern everywhere in Go.

## Type inference and untyped constants

`x := 10` makes an `int`, `y := 2.5` a `float64`. Constants without a type (`const big = 1 << 40`) are exact and take a type only when used, so `float64(items) * 0.5` and `time.Second * 2` work without conversions.

=== lesson go-operators | Operators and expressions | 55
## Arithmetic and assignment

```go
package main

import (
	"fmt"
	"math"
)

func main() {
	a, b := 17, 5
	fmt.Println(a+b, a-b, a*b, a/b, a%b) // 22 12 85 3 2
	fmt.Println(-17/5, -17%5)            // -3 -2: division truncates toward zero
	fmt.Println(17.0 / 5)                // 3.4

	total := 10
	total += 5 // also -=, *=, /=, %=
	total *= 2
	total++ // a statement, not an expression: x = y++ doesn't compile
	fmt.Println(total)

	fmt.Println(math.Pow(2, 10), math.Floor(2.7), math.Round(2.5), math.Abs(-3.2))
	fmt.Println(max(3, 9, 4), min(2.5, 1.5)) // built in since Go 1.21
}
```

`++` and `--` exist only as statements (`i++`), never inside expressions, and there's no prefix form. That removes a whole category of confusing C code.

## Comparison and logic

`==`, `!=`, `<`, `<=`, `>`, `>=` compare values of the **same type**, and give a `bool`. `&&` (and), `||` (or) and `!` (not) combine booleans and **short-circuit**: the right side is only evaluated when needed.

```go
package main

import "fmt"

func main() {
	age, member := 17, true
	hasTicket := age >= 18 || member
	fmt.Println("can enter:", hasTicket)

	names := []string{}
	// safe: names[0] is never evaluated when the list is empty
	if len(names) > 0 && names[0] == "Ada" {
		fmt.Println("first is Ada")
	}
	fmt.Println("strings compare by content:", "go" == "g"+"o", "apple" < "banana")
}
```

## Bitwise operators

Integers can also be manipulated bit by bit, which is common in networking, file formats, permissions and flags:

| Operator | Meaning |
|---|---|
| `&` | AND |
| `\|` | OR |
| `^` | XOR (as a prefix: NOT) |
| `&^` | AND NOT (bit clear) |
| `<<`, `>>` | shift left / right |

```go
package main

import "fmt"

const (
	Read  = 1 << iota // 1
	Write             // 2
	Exec              // 4
)

func main() {
	perms := Read | Write
	fmt.Printf("%03b can write: %t, can exec: %t\n", perms, perms&Write != 0, perms&Exec != 0)
	perms &^= Write // remove Write
	fmt.Printf("%03b\n", perms)
	fmt.Println(1<<10, 1024>>3)
}
```

## Precedence

Go has only five levels of binary precedence: `* / % << >> & &^`, then `+ - | ^`, then comparisons, then `&&`, then `||`. When in doubt, add parentheses; `gofmt` shows precedence by removing spaces around tighter operators (`a*b + c`).

=== lesson go-strings | Strings, bytes and runes | 70
## What a string really is

A Go `string` is an **immutable sequence of bytes**, almost always UTF-8 text. ASCII characters take 1 byte, but `é` takes 2 and many emoji 4. So:

- `len(s)` is the number of **bytes**, not characters;
- `s[i]` is a **byte** (`uint8`);
- a Unicode character is a **rune** (an alias of `int32`), written in single quotes: `'é'`;
- `for i, r := range s` walks the string **rune by rune**, with `i` the byte position.

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	word := "café"
	fmt.Println(len(word), utf8.RuneCountInString(word)) // 5 bytes, 4 runes
	fmt.Println(word[0], string(word[0]))                // 99 c
	for i, r := range word {
		fmt.Printf("%d:%c(%d) ", i, r, r)
	}
	fmt.Println()
	runes := []rune(word)                   // convert to runes to index by character
	fmt.Println(string(runes[3]), len(runes))
	fmt.Println(word[1:3])                  // slicing is by byte: "af"
}
```

Strings can't be changed in place: `s[0] = 'C'` doesn't compile. Build a new string instead.

## The strings package

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	s := "  Go is fun, Go is fast  "
	t := strings.TrimSpace(s)
	fmt.Println(strings.ToUpper(t))
	fmt.Println(strings.Contains(t, "fast"), strings.HasPrefix(t, "Go"), strings.Index(t, "fun"))
	fmt.Println(strings.Count(t, "Go"), strings.ReplaceAll(t, "Go", "Gopher"))
	parts := strings.Split("red,green,blue", ",")
	fmt.Println(len(parts), parts[1], strings.Join(parts, " | "))
	fmt.Println(strings.Fields("  many   spaces here "))
	fmt.Println(strings.Repeat("ab", 3), strings.EqualFold("GO", "go"))
	before, after, found := strings.Cut("key=value", "=")
	fmt.Println(before, after, found)
}
```

## Building strings efficiently

Because strings are immutable, `s += x` in a loop copies the whole string each time. For many pieces, use a **`strings.Builder`**:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	var sb strings.Builder
	for i := 1; i <= 5; i++ {
		fmt.Fprintf(&sb, "%d squared is %d; ", i, i*i)
	}
	sb.WriteString("done")
	fmt.Println(sb.String())
	fmt.Println(sb.Len(), "bytes")
}
```

`fmt.Fprintf` writes formatted text to anything that accepts writes; you'll meet that idea (the `io.Writer` interface) again in Module 5.

## Raw strings and escapes

Interpreted strings use double quotes and escapes (`\n`, `\t`, `\"`, `\\`, `\u00e9`). **Raw strings** use backticks: no escapes, and they can span lines, perfect for regular expressions, paths and templates:

```go
package main

import "fmt"

func main() {
	path := `C:\Users\ada\notes.txt`
	poem := `roses are red,
violets are blue`
	fmt.Println(path)
	fmt.Println(poem)
	fmt.Printf("%q\n", "tab\there")
}
```

	"fmt"
	"strings"
	"unicode/utf8"
)

func main() {
	names := []string{"  Ada King Lovelace ", "Grace Hopper", " José Ángel Núñez"}
	for _, name := range names {
		full := strings.TrimSpace(name)
		fmt.Printf("%s -> %s (%d characters)\n", full, username(full), utf8.RuneCountInString(full))
	}

func username(full string) string {
	words := strings.Fields(full)
	var sb strings.Builder
	for _, w := range words[:len(words)-1] {
		sb.WriteRune([]rune(w)[0])
	}
	sb.WriteString(words[len(words)-1])
	return strings.ToLower(sb.String())
}

- `[]rune(w)[0]` is the first character; `sb.WriteRune` appends it.

=== lesson go-input | Reading input | 55
## Reading lines with bufio.Scanner

Programs read **standard input** (what the user types, or a file piped in with `prog < data.txt`) through `os.Stdin`. The robust way is a **`bufio.Scanner`**, which reads one line at a time:

```go
// stdin: Ada | 36
package main

import (
	"bufio"
	"fmt"
	"os"
	"strconv"
	"strings"
)

func main() {
	in := bufio.NewScanner(os.Stdin)

	fmt.Print("Name: ")
	in.Scan()
	name := strings.TrimSpace(in.Text())

	fmt.Print("Age: ")
	in.Scan()
	age, err := strconv.Atoi(strings.TrimSpace(in.Text()))
	if err != nil {
		fmt.Println("\nthat's not a number:", err)
		return
	}
	fmt.Printf("\nHello %s, next year you'll be %d.\n", name, age+1)
}
```

- `in.Scan()` reads the next line and returns `false` at the end of the input; `in.Text()` returns the line without its line break.
- Everything typed is text: convert it with `strconv`, and **check the error**.
- In DevQuest the input you type in the box isn't echoed, which is why the example prints a line break before its answer.

## Reading until the end

A loop `for in.Scan() { ... }` processes every line, which is how command-line filters work:

```go
// stdin: 12 | 7 | oops | 30
package main

import (
	"bufio"
	"fmt"
	"os"
	"strconv"
)

func main() {
	in := bufio.NewScanner(os.Stdin)
	sum, count := 0, 0
	for in.Scan() {
		n, err := strconv.Atoi(in.Text())
		if err != nil {
			fmt.Printf("skipping %q\n", in.Text())
			continue
		}
		sum += n
		count++
	}
	fmt.Println("count:", count, "sum:", sum)
}
```

## fmt.Scan

`fmt.Scan(&a, &b)` reads space-separated values straight into variables (the `&` passes their addresses, see pointers in Module 4). It's handy for quick programs and contest problems, but its error handling is clumsy for real input, so prefer `bufio.Scanner`.

package main

import (
	"bufio"
	"fmt"
	"os"
	"strconv"
	"strings"
)

func main() {
	in := bufio.NewScanner(os.Stdin)
	count, sum := 0, 0
	bestName, bestScore := "", -1
	for in.Scan() {
		line := strings.TrimSpace(in.Text())
		if line == "" {
			continue
		}
		fields := strings.Fields(line)
		if len(fields) != 2 {
			fmt.Printf("invalid line: %q\n", line)
			continue
		}
		score, err := strconv.Atoi(fields[1])
		if err != nil || score < 0 || score > 100 {
			fmt.Printf("invalid line: %q\n", line)
			continue
		}
		count++
		sum += score
		if score > bestScore {
			bestName, bestScore = fields[0], score
		}
	}
	fmt.Println("students:", count)
	if count == 0 {
		return
	}
	fmt.Printf("average: %.1f\n", float64(sum)/float64(count))
	fmt.Printf("best: %s (%d)\n", bestName, bestScore)
}
