## From one file to a project

Real Go programs are split into **packages**: a package is a **folder** of `.go` files that all start with the same `package name` line. A **module** (the folder with `go.mod`) is a collection of packages released together. A typical layout:

```
shop/
├── go.mod                  module github.com/ada/shop
├── cmd/
│   └── shopd/
│       └── main.go         package main (the executable)
├── internal/
│   └── storage/
│       └── storage.go      package storage (only importable inside this module)
└── catalog/
    ├── catalog.go          package catalog
    └── catalog_test.go     tests for package catalog
```

`main.go` imports the other packages by their **module path plus folder**:

```
package main

import (
	"fmt"

	"github.com/ada/shop/catalog"
	"github.com/ada/shop/internal/storage"
)

func main() {
	store := storage.NewMemory()
	c := catalog.New(store)
	fmt.Println(c.Count())
}
```

Rules to know:

- A package name is short, lower-case, one word, and usually matches its folder (`strings`, `http`, `catalog`); avoid names like `util` or `common`.
- **Exported** names (capitalised) form the package's API; everything else is private to the package, even from other packages in the same module.
- A folder named **`internal`** can only be imported by code inside its parent folder: the compiler enforces it. Use it for code you don't want other modules to depend on.
- Import cycles are forbidden: if `catalog` imports `storage`, `storage` can't import `catalog`. That forces a clean dependency direction.
- `func init()` runs automatically when a package is loaded; keep it rare.

## Dependencies

```
go get github.com/google/uuid@latest     # add or upgrade a dependency
go mod tidy                              # add missing, remove unused
go list -m all                           # list every module in the build
go doc github.com/google/uuid.New        # read its documentation
```

`go.mod` records the required versions (Go uses **minimal version selection**: the oldest version that satisfies every requirement, so builds are reproducible), and `go.sum` stores checksums verified against the public checksum database. Third-party code is browsed on **pkg.go.dev**. Go's standard library is large, so many programs need few or no dependencies: think twice before adding one.

## Designing a package API: functional options

A package's constructor often needs many optional settings. Instead of a giant parameter list, Go code commonly uses **functional options**: variadic functions that each change one setting:

```go
package main

import (
	"fmt"
	"time"
)

type Server struct {
	addr     string
	timeout  time.Duration
	maxConns int
	logging  bool
}

type Option func(*Server)

func WithTimeout(d time.Duration) Option { return func(s *Server) { s.timeout = d } }
func WithMaxConns(n int) Option        { return func(s *Server) { s.maxConns = n } }
func WithLogging() Option              { return func(s *Server) { s.logging = true } }

func NewServer(addr string, opts ...Option) *Server {
	s := &Server{addr: addr, timeout: 30 * time.Second, maxConns: 100} // defaults
	for _, opt := range opts {
		opt(s)
	}
	return s
}

func main() {
	for _, s := range []*Server{NewServer(":8080"), NewServer(":9090", WithTimeout(5*time.Second), WithLogging())} {
		fmt.Println(s.addr, s.timeout, s.maxConns, s.logging)
	}
}
```

Callers only mention what they change, defaults live in one place, and new options can be added without breaking anyone.

package main

import (
	"fmt"
	"time"
)

type Client struct {
	retries   int
	backoff   time.Duration
	userAgent string
	verbose   bool
}

type Option func(*Client)

func WithRetries(n int) Option {
	return func(c *Client) {
		if n >= 0 {
			c.retries = n
		}
	}
}

func WithBackoff(d time.Duration) Option { return func(c *Client) { c.backoff = d } }
func WithUserAgent(s string) Option      { return func(c *Client) { c.userAgent = s } }
func Verbose() Option                    { return func(c *Client) { c.verbose = true } }

func NewClient(opts ...Option) *Client {
	c := &Client{retries: 3, backoff: 100 * time.Millisecond, userAgent: "devquest/1.0"}
	for _, opt := range opts {
		opt(c)
	}
	return c
}

func (c *Client) String() string {
	return fmt.Sprintf("retries=%d backoff=%v agent=%q verbose=%t", c.retries, c.backoff, c.userAgent, c.verbose)
}

func main() {
	fmt.Println(NewClient())
	fmt.Println(NewClient(WithRetries(5), WithBackoff(2*time.Second), Verbose()))
	fmt.Println(NewClient(WithRetries(-1), WithUserAgent("bot")))
}

## Reading and writing files

The `os` package covers files and directories; `path/filepath` builds paths with the right separator for the system:

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

func main() {
	dir, err := os.MkdirTemp("", "devquest-*") // a fresh temporary folder
	if err != nil {
		fmt.Println(err)
		return
	}
	defer os.RemoveAll(dir) // clean up, whatever happens

	path := filepath.Join(dir, "todo.txt")
	if err := os.WriteFile(path, []byte("buy milk\nwrite report\n"), 0o644); err != nil {
		fmt.Println(err)
		return
	}

	f, err := os.OpenFile(path, os.O_APPEND|os.O_WRONLY, 0o644) // open for appending
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Fprintln(f, "call Ada")
	f.Close()

	data, _ := os.ReadFile(path) // the whole file at once
	fmt.Printf("%d bytes, %d lines\n", len(data), strings.Count(string(data), "\n"))

	f, _ = os.Open(path) // read line by line: works for huge files
	defer f.Close()
	sc := bufio.NewScanner(f)
	for n := 1; sc.Scan(); n++ {
		fmt.Println(n, sc.Text())
	}

	_, err = os.ReadFile(filepath.Join(dir, "missing.txt"))
	fmt.Println("missing file is ErrNotExist:", os.IsNotExist(err))
	fmt.Println(filepath.Base(path), filepath.Ext(path))
}
```

- `0o644` is the Unix permission (owner read/write, others read); Windows mostly ignores it.
- Always **check errors** and **close** what you open (`defer f.Close()` right after a successful open). For files you write, check `Close`'s error too: it can report a failed final write.
- `filepath.WalkDir(root, fn)` visits a whole directory tree; `os.ReadDir` lists one folder.

## JSON with encoding/json

`json.Marshal` turns Go values into JSON and `json.Unmarshal` fills Go values from JSON. Only **exported** fields are included; **struct tags** choose the JSON names and options:

```go
package main

import (
	"encoding/json"
	"fmt"
	"strings"
)

type Address struct {
	City    string `json:"city"`
	Country string `json:"country"`
}

type User struct {
	ID       int               `json:"id"`
	Name     string            `json:"name"`
	Email    string            `json:"email,omitempty"` // left out when empty
	Roles    []string          `json:"roles"`
	Address  *Address          `json:"address,omitempty"`
	Password string            `json:"-"` // never serialized
	Extra    map[string]string `json:"extra,omitempty"`
}

func main() {
	u := User{ID: 1, Name: "Ada", Roles: []string{"admin"}, Address: &Address{"London", "UK"}, Password: "secret"}
	data, err := json.Marshal(u)
	fmt.Println(string(data), err)

	pretty, _ := json.MarshalIndent(u, "", "  ")
	fmt.Println(string(pretty))

	var back User
	err = json.Unmarshal([]byte(`{"id":2,"name":"Grace","roles":["dev"],"unknown":true}`), &back)
	fmt.Printf("%+v %v\n", back, err)

	err = json.Unmarshal([]byte(`{"id":"two"}`), &back)
	fmt.Println(err)

	var anything map[string]any // unknown shape: maps, []any, float64, string, bool, nil
	json.NewDecoder(strings.NewReader(`{"temp": 21.5, "tags": ["a", "b"]}`)).Decode(&anything)
	fmt.Println(anything["temp"], anything["tags"])
}
```

- Pass a **pointer** to `Unmarshal` so it can fill the value. Unknown JSON fields are ignored; missing ones keep their zero values.
- JSON numbers decoded into `any` become `float64`.
- `json.NewEncoder(w)` and `json.NewDecoder(r)` stream JSON to and from any `io.Writer` / `io.Reader` (files, HTTP bodies).
- Other formats in the standard library: `encoding/csv`, `encoding/xml`, `encoding/binary`, `encoding/base64`.

package main

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
)

type Task struct {
	ID    int      `json:"id"`
	Title string   `json:"title"`
	Done  bool     `json:"done"`
	Tags  []string `json:"tags,omitempty"`
}

type Store struct{ path string }

func (s Store) Load() ([]Task, error) {
	data, err := os.ReadFile(s.path)
	if errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var tasks []Task
	if err := json.Unmarshal(data, &tasks); err != nil {
		return nil, fmt.Errorf("decode %s: %w", s.path, err)
	}
	return tasks, nil
}

func (s Store) Save(tasks []Task) error {
	data, err := json.MarshalIndent(tasks, "", "  ")
	if err != nil {
		return err
	}
	return os.WriteFile(s.path, data, 0o644)
}

func (s Store) Add(title string, tags ...string) (Task, error) {
	tasks, err := s.Load()
	if err != nil {
		return Task{}, err
	}
	next := 1
	for _, t := range tasks {
		next = max(next, t.ID+1)
	}
	task := Task{ID: next, Title: title, Tags: tags}
	if err := s.Save(append(tasks, task)); err != nil {
		return Task{}, err
	}
	return task, nil
}

func main() {
	dir, _ := os.MkdirTemp("", "tasks-*")
	defer os.RemoveAll(dir)
	store := Store{filepath.Join(dir, "tasks.json")}
	tasks, err := store.Load()
	fmt.Println("before:", len(tasks), "tasks", errString(err))
	for _, t := range []struct {
		title string
		tags  []string
	}{{"write report", []string{"work"}}, {"buy milk", nil}} {
		task, err := store.Add(t.title, t.tags...)
		if err != nil {
			fmt.Println(err)
			return
		}
		fmt.Println("added", task.ID, task.Title)
	}
	data, _ := os.ReadFile(store.path)
	fmt.Println(string(data))
	tasks, _ = store.Load()
	fmt.Println("after reload:", len(tasks), "tasks, first tag", tasks[0].Tags[0])
}

func errString(err error) string {
	if err != nil {
		return err.Error()
	}
	return ""
}

=== lesson go-testing | Testing | 75
## Tests are part of the language toolchain

Go has testing built in: no framework to install. Tests live next to the code in files ending in **`_test.go`**, in functions named **`TestXxx(t *testing.T)`**, and `go test ./...` runs them:

```
// price.go
package shop

func Discount(cents, percent int) int {
	return cents - cents*percent/100
}
```

```
// price_test.go
package shop

import "testing"

func TestDiscount(t *testing.T) {
	got := Discount(1000, 15)
	if got != 850 {
		t.Errorf("Discount(1000, 15) = %d, want 850", got)
	}
}
```

`t.Errorf` reports a failure and continues; `t.Fatalf` stops this test. The message pattern **`got X, want Y`** is the Go convention. There are no assertion helpers in the standard library on purpose (third-party ones such as `testify` exist).

## Table-driven tests

The most common Go testing style lists cases in a **table** and loops over them, with **`t.Run`** giving each case its own name (and `go test -run TestDiscount/zero` runs one):

```
func TestDiscount(t *testing.T) {
	tests := []struct {
		name           string
		cents, percent int
		want           int
	}{
		{"normal", 1000, 15, 850},
		{"zero percent", 1000, 0, 1000},
		{"full price off", 999, 100, 0},
		{"rounds down", 999, 10, 900},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			if got := Discount(tt.cents, tt.percent); got != tt.want {
				t.Errorf("Discount(%d, %d) = %d, want %d", tt.cents, tt.percent, got, tt.want)
			}
		})
	}
}
```

Adding a case is one line. Here is the same idea as a runnable program, with a tiny runner standing in for `go test` (the bug it finds is real):

```go
package main

import (
	"fmt"
	"strings"
)

// Slugify turns a title into a URL part: "Hello, World!" -> "hello-world"
func Slugify(title string) string {
	var sb strings.Builder
	for _, r := range strings.ToLower(title) {
		switch {
		case r >= 'a' && r <= 'z', r >= '0' && r <= '9':
			sb.WriteRune(r)
		case r == ' ':
			sb.WriteRune('-')
		}
	}
	return sb.String()
}

func main() {
	tests := []struct{ name, in, want string }{
		{"simple", "Hello World", "hello-world"},
		{"punctuation", "Hello, World!", "hello-world"},
		{"digits", "Go 1.23 Released", "go-123-released"},
		{"double spaces", "a  b", "a-b"},
	}
	failed := 0
	for _, tt := range tests {
		if got := Slugify(tt.in); got != tt.want {
			fmt.Printf("--- FAIL: %s: Slugify(%q) = %q, want %q\n", tt.name, tt.in, got, tt.want)
			failed++
		} else {
			fmt.Printf("--- PASS: %s\n", tt.name)
		}
	}
	fmt.Println(len(tests)-failed, "passed,", failed, "failed")
}
```

## More from the testing package

- **Benchmarks**: `func BenchmarkX(b *testing.B) { for b.Loop() { X() } }`, run with `go test -bench=. -benchmem` to see time and allocations per operation.
- **Fuzzing**: `func FuzzX(f *testing.F)` generates random inputs to find crashes (`go test -fuzz=FuzzX`).
- **Examples**: `func ExampleSlugify()` with an `// Output:` comment is compiled, run and shown in the documentation.
- **Coverage**: `go test -cover` (and `-coverprofile` for an HTML report).
- **`t.Helper()`**, **`t.Cleanup(f)`**, **`t.TempDir()`** and **`t.Parallel()`** keep tests short and independent.
- **`net/http/httptest`** tests HTTP handlers without a network (next lesson).
- Test **behaviour through the package's API**; to replace a dependency (a clock, a database, an HTTP service), accept an **interface** and pass a fake in the test.

## A web server in the standard library

`net/http` is production-quality: many companies run it directly, without a framework. Since Go 1.22, the router (**`http.ServeMux`**) understands methods and path parameters:

```
package main

import (
	"encoding/json"
	"log"
	"net/http"
)

type Todo struct {
	ID    int    `json:"id"`
	Title string `json:"title"`
}

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /hello", func(w http.ResponseWriter, r *http.Request) {
		w.Write([]byte("hello, " + r.URL.Query().Get("name")))
	})
	mux.HandleFunc("GET /todos/{id}", func(w http.ResponseWriter, r *http.Request) {
		id := r.PathValue("id")
		w.Header().Set("Content-Type", "application/json")
		json.NewEncoder(w).Encode(Todo{ID: 1, Title: "todo " + id})
	})
	log.Fatal(http.ListenAndServe(":8080", mux))
}
```

- A **handler** receives the **`http.ResponseWriter`** (an `io.Writer` for the body, plus headers and status) and the **`*http.Request`** (method, URL, headers, body).
- Patterns: `"GET /todos/{id}"` matches the method and captures `{id}` (read with `r.PathValue`); `"/static/"` matches everything below; the most specific pattern wins.
- `http.Error(w, "not found", http.StatusNotFound)` sends an error; `w.WriteHeader(201)` sets another status (call it before writing the body).
- Every request runs in **its own goroutine**: handlers must be safe for concurrent use (protect shared data with a mutex).

## A complete server and client you can run

`httptest.NewServer` starts a real server on a free local port, which makes this runnable here. The client is `http.Get` / `http.Client`:

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"strings"
	"sync"
)

type Note struct {
	ID   int    `json:"id"`
	Text string `json:"text"`
}

type NoteServer struct {
	mu    sync.Mutex
	notes []Note
}

func (s *NoteServer) routes() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /notes", func(w http.ResponseWriter, r *http.Request) {
		s.mu.Lock()
		defer s.mu.Unlock()
		w.Header().Set("Content-Type", "application/json")
		json.NewEncoder(w).Encode(s.notes)
	})
	mux.HandleFunc("POST /notes", func(w http.ResponseWriter, r *http.Request) {
		var n Note
		if err := json.NewDecoder(r.Body).Decode(&n); err != nil || n.Text == "" {
			http.Error(w, "invalid note", http.StatusBadRequest)
			return
		}
		s.mu.Lock()
		n.ID = len(s.notes) + 1
		s.notes = append(s.notes, n)
		s.mu.Unlock()
		w.WriteHeader(http.StatusCreated)
		json.NewEncoder(w).Encode(n)
	})
	return mux
}

func main() {
	srv := httptest.NewServer((&NoteServer{}).routes())
	defer srv.Close()

	for _, body := range []string{`{"text":"buy milk"}`, `{"text":""}`, `{"text":"call Ada"}`} {
		resp, err := http.Post(srv.URL+"/notes", "application/json", strings.NewReader(body))
		if err != nil {
			fmt.Println(err)
			return
		}
		data, _ := io.ReadAll(resp.Body)
		resp.Body.Close()
		fmt.Print(resp.StatusCode, " ", string(data))
	}

	resp, _ := http.Get(srv.URL + "/notes")
	defer resp.Body.Close()
	var notes []Note
	json.NewDecoder(resp.Body).Decode(&notes)
	fmt.Println(resp.StatusCode, resp.Header.Get("Content-Type"), notes)
}
```

Client rules: always **close the response body**; check the status code (a 404 is not a Go error); for production, create an `http.Client{Timeout: 10 * time.Second}` instead of the default client, which never times out, and pass a context with `http.NewRequestWithContext`.

## Middleware

A **middleware** wraps a handler to add behaviour around every request (logging, authentication, recovering from panics, CORS). Because `http.Handler` is an interface with one method, middleware is just a function from handler to handler:

```
func logging(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		next.ServeHTTP(w, r)
		log.Printf("%s %s %v", r.Method, r.URL.Path, time.Since(start))
	})
}

http.ListenAndServe(":8080", logging(mux))
```

	json.NewEncoder(w).Encode(v)

	mux := http.NewServeMux()
	mux.HandleFunc("GET /items/{name}", func(w http.ResponseWriter, r *http.Request) {
		name := r.PathValue("name")
		inv.mu.Lock()
		n, ok := inv.stock[name]
		inv.mu.Unlock()
		if !ok {
			http.Error(w, "unknown item", http.StatusNotFound)
			return

		writeJSON(w, item{name, n})

## reflect: looking at types at run time

The **`reflect`** package inspects values whose type isn't known at compile time. It's what `encoding/json`, `fmt` and validation libraries use to walk through struct fields and read their tags:

```go
package main

import (
	"fmt"
	"reflect"
)

type Config struct {
	Host    string `env:"HOST" default:"localhost"`
	Port    int    `env:"PORT" default:"8080"`
	Debug   bool   `env:"DEBUG"`
	secret  string
}

func main() {
	c := Config{Host: "example.com", Port: 443, secret: "x"}
	t := reflect.TypeOf(c)
	v := reflect.ValueOf(c)
	fmt.Println(t.Name(), t.Kind(), t.NumField())
	for i := range t.NumField() {
		f := t.Field(i)
		if !f.IsExported() {
			fmt.Println("skipping unexported", f.Name)
			continue
		}
		fmt.Printf("%-6s %-7s env=%-6s default=%-10q value=%v\n", f.Name, f.Type, f.Tag.Get("env"), f.Tag.Get("default"), v.Field(i))
	}

	// to modify a value through reflection, start from a pointer
	pv := reflect.ValueOf(&c).Elem()
	pv.FieldByName("Port").SetInt(8443)
	fmt.Println(c.Port)

	for _, x := range []any{42, "hi", []int{1}, map[string]int{}, c, &c} {
		fmt.Print(reflect.TypeOf(x).Kind(), " ")
	}
	fmt.Println()
}
```

- `reflect.TypeOf(x)` describes the type (name, kind, fields, methods, tags); `reflect.ValueOf(x)` holds the value.
- **Kind** is the basic category (`struct`, `slice`, `map`, `ptr`, `int`…), while the type can be a named type such as `Config`.
- Setting values requires an **addressable** value: `reflect.ValueOf(&x).Elem()`.

Reflection is **slow, verbose and checked only at run time**: a typo in a field name panics instead of failing to compile. Prefer interfaces and generics; use reflection for generic infrastructure (serialisation, validation, dependency injection), or generate code with **`go generate`** instead.

## unsafe and the memory layout

`unsafe` lets you step outside Go's type safety: convert between pointer types and inspect memory layout. It's used in performance-critical libraries and when talking to C; ordinary code never needs it. `unsafe.Sizeof` shows how struct **field order** affects size, because fields are aligned in memory:

```go
package main

import (
	"fmt"
	"unsafe"
)

type Loose struct {
	A bool  // 1 byte + 7 bytes padding
	B int64 // 8 bytes
	C bool  // 1 byte + 7 bytes padding
}

type Packed struct {
	B int64 // 8 bytes
	A bool  // 1 byte
	C bool  // 1 byte + 6 bytes padding
}

func main() {
	fmt.Println(unsafe.Sizeof(Loose{}), unsafe.Sizeof(Packed{}))
	fmt.Println(unsafe.Sizeof(""), unsafe.Sizeof([]int{}), unsafe.Sizeof(map[int]int{}), unsafe.Sizeof(any(nil)))
}
```

A string header is 16 bytes (pointer + length), a slice 24 (pointer, length, capacity), a map just a pointer, an interface 16 (type + data). Knowing this explains why passing slices and strings is cheap.

## cgo and calling C

**cgo** lets Go call C libraries (`import "C"` with a comment containing C code). It works, but it slows builds, complicates cross-compilation and makes each call more expensive, so Go programmers prefer pure-Go libraries whenever they exist.

package main

import (
	"fmt"
	"reflect"
	"strconv"
	"strings"
)

type SignUp struct {
	Name  string `validate:"required,min=2"`
	Age   int    `validate:"min=18,max=130"`
	Email string `validate:"required"`
	Note  string
}

type Coupon struct {
	Code string `validate:"required,max=4"`
}

func Validate(v any) []string {
	var errs []string
	val := reflect.Indirect(reflect.ValueOf(v))
	t := val.Type()
	for i := range t.NumField() {
		f := t.Field(i)
		tag := f.Tag.Get("validate")
		if !f.IsExported() || tag == "" {
			continue
		}
		fv := val.Field(i)
		var size int
		switch fv.Kind() {
		case reflect.String:
			size = fv.Len()
		case reflect.Int:
			size = int(fv.Int())
		}
		for _, rule := range strings.Split(tag, ",") {
			name, arg, _ := strings.Cut(rule, "=")
			n, _ := strconv.Atoi(arg)
			failed := false
			switch name {
			case "required":
				failed = fv.IsZero()
			case "min":
				failed = size < n
			case "max":
				failed = size > n
			}
			if failed {
				errs = append(errs, f.Name+": "+rule)
			}
		}
	}
	return errs
}

func main() {
	inputs := []any{
		SignUp{Name: "Ada", Age: 36, Email: "ada@example.com"},
		&SignUp{Name: "", Age: 12},
		Coupon{Code: "SUMMER"},
		SignUp{Name: "Al", Age: 200, Email: "x"},
	}
	for _, in := range inputs {
		errs := Validate(in)
		if len(errs) == 0 {
			fmt.Println("valid")
		}
		for _, e := range errs {
			fmt.Println(e)
		}
	}

package main

import (
	"bufio"
	"encoding/json"
	"fmt"
	"os"
	"slices"
	"strings"
)

type Entry struct {
	Level   string `json:"level"`
	Service string `json:"service"`
	Ms      int    `json:"ms"`
	Msg     string `json:"msg"`
}

type Summary struct {
	Total    int            `json:"total"`
	Invalid  int            `json:"invalid"`
	ByLevel  map[string]int `json:"by_level"`
	Slowest  *Entry         `json:"slowest,omitempty"`
	Services []string       `json:"services"`
}

func summarize(sc *bufio.Scanner) Summary {
	s := Summary{ByLevel: map[string]int{}, Services: []string{}}
	for sc.Scan() {
		line := strings.TrimSpace(sc.Text())
		if line == "" {
			continue
		}
		var e Entry
		if err := json.Unmarshal([]byte(line), &e); err != nil {
			s.Invalid++
			continue
		}
		s.Total++
		s.ByLevel[e.Level]++
		if s.Slowest == nil || e.Ms > s.Slowest.Ms {
			s.Slowest = &e
		}
		if e.Level == "error" && !slices.Contains(s.Services, e.Service) {
			s.Services = append(s.Services, e.Service)
		}
	}
	slices.Sort(s.Services)
	return s
}

func main() {
	s := summarize(bufio.NewScanner(os.Stdin))
	out, err := json.MarshalIndent(s, "", "  ")
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	fmt.Println(string(out))
}
