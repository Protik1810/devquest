## Functions attached to types

A **method** is a function with a **receiver**: the value it's called on, written before the name. Go has no classes; any named type you define can have methods, structs most often:

```go
package main

import (
	"fmt"
	"math"
)

type Point struct{ X, Y float64 }

// value receiver: p is a copy of the point
func (p Point) Distance(q Point) float64 {
	return math.Hypot(q.X-p.X, q.Y-p.Y)
}

// pointer receiver: changes the caller's point
func (p *Point) Move(dx, dy float64) {
	p.X += dx
	p.Y += dy
}

func (p Point) String() string {
	return fmt.Sprintf("(%g, %g)", p.X, p.Y)
}

type Celsius float64 // methods work on any named type, not only structs

func (c Celsius) Fahrenheit() float64 { return float64(c)*9/5 + 32 }

func main() {
	a := Point{0, 0}
	b := Point{3, 4}
	fmt.Println(a.Distance(b))
	a.Move(1, 1) // Go takes &a automatically because a is a variable
	fmt.Println(a, b) // fmt calls the String method
	fmt.Println(Celsius(100).Fahrenheit())

	move := a.Move // a method value: bound to a
	move(10, 0)
	fmt.Println(a)
}
```

## Value or pointer receiver?

| Use a pointer receiver `(p *T)` when | Use a value receiver `(p T)` when |
|---|---|
| the method **changes** the receiver | the type is a small value (a point, a money amount, a colour) |
| the struct is large (avoid copying) | the method only reads |
| the type contains a mutex or must not be copied | the type is a map, func or channel (already a reference) |

**Be consistent**: if some methods of a type need pointer receivers, give all its methods pointer receivers. Go calls methods conveniently in both directions: `v.Move()` on an addressable variable takes its address, and `p.Distance(q)` on a pointer dereferences it.

## Encapsulation with packages

Go's unit of encapsulation is the **package**, not the type: unexported (lower-case) fields and methods are invisible outside the package. A type keeps its invariants by hiding its fields and offering methods:

```go
package main

import (
	"errors"
	"fmt"
)

type Account struct {
	owner   string
	balance int // in cents, unexported: other packages can't touch it
	history []string
}

var ErrInsufficient = errors.New("insufficient funds")

func NewAccount(owner string) *Account { return &Account{owner: owner} }

func (a *Account) Deposit(cents int) {
	a.balance += cents
	a.history = append(a.history, fmt.Sprintf("+%d", cents))
}

func (a *Account) Withdraw(cents int) error {
	if cents > a.balance {
		return fmt.Errorf("withdraw %d from %s: %w", cents, a.owner, ErrInsufficient)
	}
	a.balance -= cents
	a.history = append(a.history, fmt.Sprintf("-%d", cents))
	return nil
}

func (a *Account) Balance() int { return a.balance } // a getter is named Balance, not GetBalance

func main() {
	acc := NewAccount("ada")
	acc.Deposit(5000)
	fmt.Println(acc.Withdraw(2000), acc.Withdraw(9000))
	fmt.Println(acc.Balance(), acc.history)
}
```

(Inside one file everything is in the same package, so `main` can still read `acc.history`; another package couldn't.)

## Methods of embedded types are promoted

```go
package main

import "fmt"

type Logger struct{ prefix string }

func (l Logger) Log(msg string) { fmt.Println(l.prefix + msg) }

type Service struct {
	Logger // embedded: Service gets the Log method
	name   string
}

func (s Service) Start() { s.Log("starting " + s.name) }

func main() {
	svc := Service{Logger{"[svc] "}, "billing"}
	svc.Start()
	svc.Log("direct call")
}
```

This is how Go reuses behaviour: by **composition**. The outer type can define its own `Log` to replace the promoted one, but there's no `super` and no virtual dispatch through the embedded type.

package main

import (
	"fmt"
	"strings"
)

type Stack struct {
	items []int
}

func (s *Stack) Push(v int) {
	s.items = append(s.items, v)
}

func (s *Stack) Pop() (int, bool) {
	if len(s.items) == 0 {
		return 0, false
	}
	v := s.items[len(s.items)-1]
	s.items = s.items[:len(s.items)-1]
	return v, true
}

func (s *Stack) Peek() (int, bool) {
	if len(s.items) == 0 {
		return 0, false
	}
	return s.items[len(s.items)-1], true
}

func (s *Stack) Len() int { return len(s.items) }

func (s *Stack) String() string {
	parts := make([]string, len(s.items))
	for i, v := range s.items {
		parts[i] = fmt.Sprint(v)
	}
	return "[" + strings.Join(parts, " ") + ">"
}

func main() {
	var s Stack
	s.Push(1)
	s.Push(2)
	s.Push(3)
	fmt.Println(s.String())
	v, ok := s.Pop()
	fmt.Println("pop:", v, ok)
	v, ok = s.Peek()
	fmt.Println("peek:", v, ok)
	fmt.Println("len:", s.Len())
	fmt.Println(s.String())
	for range 3 {
		v, ok = s.Pop()
		fmt.Println("pop:", v, ok)
	}
	fmt.Println(s.String())
}

=== lesson go-interfaces | Interfaces | 80
## Behaviour as a type

An **interface** lists methods. Any type that has those methods **satisfies** it automatically: there's no `implements` keyword. This is Go's main tool for polymorphism:

```go
package main

import (
	"fmt"
	"math"
)

type Shape interface {
	Area() float64
	Perimeter() float64
}

type Rect struct{ W, H float64 }
type Circle struct{ R float64 }

func (r Rect) Area() float64       { return r.W * r.H }
func (r Rect) Perimeter() float64  { return 2 * (r.W + r.H) }
func (c Circle) Area() float64     { return math.Pi * c.R * c.R }
func (c Circle) Perimeter() float64 { return 2 * math.Pi * c.R }

func describe(s Shape) string {
	return fmt.Sprintf("%T area %.2f perimeter %.2f", s, s.Area(), s.Perimeter())
}

func main() {
	shapes := []Shape{Rect{3, 4}, Circle{1}, Rect{1, 1}}
	total := 0.0
	for _, s := range shapes {
		fmt.Println(describe(s))
		total += s.Area()
	}
	fmt.Printf("total area %.2f\n", total)
}
```

Because satisfaction is implicit, you can define an interface **where it's used**, for types written long before by someone else. Go interfaces are usually **small**: one or two methods.

## Interfaces you'll meet everywhere

| Interface | Method | Used for |
|---|---|---|
| `fmt.Stringer` | `String() string` | how fmt prints a value |
| `error` | `Error() string` | every error |
| `io.Reader` | `Read(p []byte) (n int, err error)` | anything you can read bytes from: files, network, strings |
| `io.Writer` | `Write(p []byte) (n int, err error)` | anything you can write to: files, buffers, HTTP responses |
| `sort.Interface` | `Len`, `Less`, `Swap` | the older sorting API |

## Custom error types

Since `error` is an interface, any type with an `Error() string` method is an error. A custom error type carries extra information, which callers extract with **`errors.As`**:

```go
package main

import (
	"errors"
	"fmt"
)

type ValidationError struct {
	Field  string
	Reason string
}

func (e *ValidationError) Error() string {
	return fmt.Sprintf("invalid %s: %s", e.Field, e.Reason)
}

func register(email string, age int) error {
	if age < 16 {
		return &ValidationError{"age", "must be at least 16"}
	}
	if email == "" {
		return &ValidationError{"email", "is required"}
	}
	return nil
}

func main() {
	err := fmt.Errorf("sign-up failed: %w", register("ada@example.com", 12))
	fmt.Println(err)
	var ve *ValidationError
	if errors.As(err, &ve) {
		fmt.Println("highlight the field:", ve.Field)
	}
}
```

## Type assertions and type switches

An interface value holds a **concrete type and a value**. You can ask what's inside:

```go
package main

import "fmt"

func describe(v any) string { // any = interface{}: every type satisfies it
	switch x := v.(type) {
	case nil:
		return "nothing"
	case int:
		return fmt.Sprintf("int %d, doubled %d", x, x*2)
	case string:
		return fmt.Sprintf("string of %d bytes", len(x))
	case fmt.Stringer:
		return "a Stringer: " + x.String()
	case []int:
		return fmt.Sprintf("slice of %d ints", len(x))
	default:
		return fmt.Sprintf("something else: %T", x)
	}
}

type Color struct{ R, G, B uint8 }

func (c Color) String() string { return fmt.Sprintf("#%02x%02x%02x", c.R, c.G, c.B) }

func main() {
	for _, v := range []any{42, "héllo", Color{255, 128, 0}, []int{1, 2}, 3.5, nil} {
		fmt.Println(describe(v))
	}
	var s fmt.Stringer = Color{1, 2, 3}
	c, ok := s.(Color) // a type assertion with comma ok
	fmt.Println(c.R, ok)
	_, ok = s.(interface{ Area() float64 })
	fmt.Println(ok)
}
```

`v.(T)` without `ok` **panics** if `v` doesn't hold a `T`; prefer the comma-ok form or a type switch. Use `any` sparingly: it throws away type checking, so it's for truly heterogeneous data (JSON, printing).

## The nil interface trap

An interface is `nil` only when it holds **no type and no value**. An interface holding a nil *pointer* is **not** nil:

```go
package main

import "fmt"

type MyErr struct{}

func (*MyErr) Error() string { return "boom" }

func mayFail(fail bool) error {
	var e *MyErr // nil pointer
	if fail {
		e = &MyErr{}
	}
	return e // WRONG: returns a non-nil interface holding a nil *MyErr
}

func mayFailFixed(fail bool) error {
	if fail {
		return &MyErr{}
	}
	return nil // return a literal nil
}

func main() {
	fmt.Println(mayFail(false) == nil, mayFailFixed(false) == nil)
}
```

Always `return nil` directly for "no error", never a typed nil pointer.

	"errors"
	"fmt"
	"strings"
)

type Notifier interface {
	Send(to, msg string) error
	Name() string
}

type SendError struct {
	Channel, To string
}

func (e *SendError) Error() string {
	return fmt.Sprintf("%s: cannot send to %q", e.Channel, e.To)
}

type EmailNotifier struct{ From string }

func (e EmailNotifier) Name() string { return "email" }

func (e EmailNotifier) Send(to, msg string) error {
	if !strings.Contains(to, "@") {
		return &SendError{Channel: "email", To: to}
	}
	fmt.Printf("email from %s to %s: %s\n", e.From, to, msg)
	return nil
}

type SMSNotifier struct{}

func (SMSNotifier) Name() string { return "sms" }

	if !strings.HasPrefix(to, "+") {
		return &SendError{Channel: "sms", To: to}
	}
	if len(msg) > 20 {
		msg = msg[:20] + "…"
	}
	fmt.Printf("sms to %s: %s\n", to, msg)
	return nil
}

				fmt.Println(err)

					failures[se.Channel]++

		}
	}
	return failures

## Two tiny interfaces, a whole ecosystem

`io.Reader` and `io.Writer` have one method each, and nearly everything that moves bytes implements them: files, network connections, HTTP bodies, compressors, hashes, buffers, `os.Stdout`. Code written against these interfaces works with all of them:

```go
package main

import (
	"bufio"
	"bytes"
	"fmt"
	"io"
	"os"
	"strings"
)

// countLines works with ANY reader: a file, a network stream, a string...
func countLines(r io.Reader) (int, error) {
	sc := bufio.NewScanner(r)
	n := 0
	for sc.Scan() {
		n++
	}
	return n, sc.Err()
}

func main() {
	n, err := countLines(strings.NewReader("one\ntwo\nthree\n"))
	fmt.Println(n, err)

	var buf bytes.Buffer                 // a Writer (and Reader) in memory
	fmt.Fprintf(&buf, "total: %d\n", 42) // Fprintf writes to any io.Writer
	buf.WriteString("done\n")
	io.Copy(os.Stdout, &buf) // copy from a reader to a writer

	w := io.MultiWriter(os.Stdout, &buf) // write to two places at once
	fmt.Fprintln(w, "logged twice")
	fmt.Print("buffer now holds: ", buf.String())
}
```

## Building your own reader or writer

Implementing the interface is enough to plug into everything else. A writer that counts the bytes passing through, and a reader that upper-cases another reader:

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"os"
	"strings"
)

type CountingWriter struct {
	W     io.Writer
	Count int
}

func (c *CountingWriter) Write(p []byte) (int, error) {
	n, err := c.W.Write(p)
	c.Count += n
	return n, err
}

type upperReader struct{ r io.Reader }

func (u upperReader) Read(p []byte) (int, error) {
	n, err := u.r.Read(p)
	copy(p, bytes.ToUpper(p[:n]))
	return n, err
}

func main() {
	cw := &CountingWriter{W: os.Stdout}
	io.Copy(cw, upperReader{strings.NewReader("readers wrap readers\n")})
	fmt.Println("bytes written:", cw.Count)
}
```

Wrapping one reader or writer in another (buffering with `bufio`, compression with `gzip`, hashing with `io.TeeReader`) is the **decorator** pattern, and in Go it falls out of small interfaces.

## Composing interfaces

Interfaces can embed other interfaces. The standard library defines `io.ReadWriter`, `io.ReadCloser` and others this way:

```
type ReadWriter interface {
	Reader
	Writer
}
```

**Accept interfaces, return structs**: functions take the smallest interface they need (an `io.Reader`, not an `*os.File`), which makes them reusable and easy to test with a `strings.Reader`; constructors return concrete types so callers get every method.

## Type parameters

Since Go 1.18, functions and types can take **type parameters** in square brackets. A **constraint** says which types are allowed:

```go
package main

import (
	"cmp"
	"fmt"
	"strings"
)

// Map works for any element type T and result type U
func Map[T, U any](items []T, f func(T) U) []U {
	out := make([]U, 0, len(items))
	for _, it := range items {
		out = append(out, f(it))
	}
	return out
}

// MaxOf needs ordered types: numbers and strings (cmp.Ordered)
func MaxOf[T cmp.Ordered](items ...T) T {
	best := items[0]
	for _, it := range items[1:] {
		if it > best {
			best = it
		}
	}
	return best
}

// Index needs ==, so the constraint is comparable
func Index[T comparable](items []T, target T) int {
	for i, it := range items {
		if it == target {
			return i
		}
	}
	return -1
}

func main() {
	fmt.Println(Map([]int{1, 2, 3}, func(n int) string { return strings.Repeat("*", n) }))
	fmt.Println(MaxOf(3, 9, 4), MaxOf("pear", "apple"), MaxOf(2.5, -1))
	fmt.Println(Index([]string{"a", "b", "c"}, "c"), Index([]int{1, 2}, 5))
	fmt.Println(Map[float64, int]([]float64{1.9, 2.1}, func(f float64) int { return int(f) })) // explicit types
}
```

Usually the compiler **infers** the type arguments from the arguments, as in `MaxOf(3, 9, 4)`.

## Constraints are interfaces

A constraint is an interface, which may list **types** with `|`. `~int` means "int or any type whose underlying type is int":

```go
package main

import "fmt"

type Number interface {
	~int | ~int64 | ~float64
}

func Sum[T Number](nums []T) T {
	var total T // the zero value of T
	for _, n := range nums {
		total += n
	}
	return total
}

type Cents int64 // underlying type int64: allowed by ~int64

func main() {
	fmt.Println(Sum([]int{1, 2, 3}), Sum([]float64{0.5, 0.25}), Sum([]Cents{199, 250}))
}
```

## Generic types

Types can be generic too. A typed **set** and a **cache** are typical examples:

```go
package main

import (
	"cmp"
	"fmt"
	"maps"
	"slices"
)

type Set[T cmp.Ordered] struct {
	items map[T]struct{}
}

func NewSet[T cmp.Ordered](values ...T) *Set[T] {
	s := &Set[T]{items: map[T]struct{}{}}
	for _, v := range values {
		s.Add(v)
	}
	return s
}

func (s *Set[T]) Add(v T)           { s.items[v] = struct{}{} }
func (s *Set[T]) Has(v T) bool      { _, ok := s.items[v]; return ok }
func (s *Set[T]) Len() int          { return len(s.items) }
func (s *Set[T]) Sorted() []T       { return slices.Sorted(maps.Keys(s.items)) }

func Intersect[T cmp.Ordered](a, b *Set[T]) *Set[T] {
	out := NewSet[T]()
	for v := range a.items {
		if b.Has(v) {
			out.Add(v)
		}
	}
	return out
}

func main() {
	langs := NewSet("go", "rust", "python")
	fast := NewSet("go", "rust", "c")
	fmt.Println(langs.Len(), langs.Has("go"), Intersect(langs, fast).Sorted())
	nums := NewSet(3, 1, 3, 2)
	fmt.Println(nums.Sorted())
}
```

## When to use generics

Use them for **containers** (sets, queues, caches, trees) and **algorithms over collections** (map, filter, max, binary search) that would otherwise be duplicated per type or use `any`. Don't use them when an ordinary interface works: if a function only needs to call `String()`, take a `fmt.Stringer`. The standard `slices`, `maps` and `cmp` packages show the style.

import (

	"fmt"
	"maps"
	"slices"

type Product struct {
	Name     string
	Category string
	Price    float64
}

func Filter[T any](items []T, keep func(T) bool) []T {
	var out []T
	for _, it := range items {
		if keep(it) {
			out = append(out, it)
		}
	}
	return out
}

func GroupBy[T any, K comparable](items []T, key func(T) K) map[K][]T {
	groups := map[K][]T{}
	for _, it := range items {
		k := key(it)
		groups[k] = append(groups[k], it)
	}
	return groups
}

func SumBy[T any, N int | float64](items []T, value func(T) N) N {
	var total N
	for _, it := range items {
		total += value(it)
	}
	return total
}

type Pair[K comparable, V any] struct {
	Key   K
	Value V
}

func (p Pair[K, V]) String() string { return fmt.Sprintf("%v=%v", p.Key, p.Value) }

func SortedPairs[K cmp.Ordered, V any](m map[K]V) []Pair[K, V] {
	var out []Pair[K, V]
	for _, k := range slices.Sorted(maps.Keys(m)) {
		out = append(out, Pair[K, V]{k, m[k]})
	}
	return out
}

	}

## Range over functions

Go 1.23 lets `for ... range` loop over **functions**. An iterator is a function that receives a `yield` callback and calls it for each value; when `yield` returns `false` (the loop did `break`), the iterator stops. The `iter` package names the two shapes: **`iter.Seq[V]`** (one value per step) and **`iter.Seq2[K, V]`** (two):

```go
package main

import (
	"fmt"
	"iter"
)

// Countdown yields n, n-1, ..., 1
func Countdown(n int) iter.Seq[int] {
	return func(yield func(int) bool) {
		for i := n; i > 0; i-- {
			if !yield(i) {
				return // the caller broke out of the loop
			}
		}
	}
}

// Fibonacci is infinite: the caller decides when to stop
func Fibonacci() iter.Seq2[int, int] {
	return func(yield func(int, int) bool) {
		a, b := 0, 1
		for i := 0; ; i++ {
			if !yield(i, a) {
				return
			}
			a, b = b, a+b
		}
	}
}

func main() {
	for n := range Countdown(3) {
		fmt.Print(n, " ")
	}
	fmt.Println("liftoff")

	for i, f := range Fibonacci() {
		if f > 100 {
			break
		}
		fmt.Printf("F%d=%d ", i, f)
	}
	fmt.Println()
}
```

## The standard library speaks iterators

`maps.Keys`, `maps.Values` and `maps.All` return iterators, `slices.All`, `slices.Values` and `slices.Backward` produce them, and `slices.Collect` and `slices.Sorted` consume them. Your own iterators work with all of these:

```go
package main

import (
	"fmt"
	"iter"
	"slices"
	"strings"
)

func Filter[V any](seq iter.Seq[V], keep func(V) bool) iter.Seq[V] {
	return func(yield func(V) bool) {
		for v := range seq {
			if keep(v) && !yield(v) {
				return
			}
		}
	}
}

func main() {
	words := strings.Fields("go is simple and go is fast")
	long := Filter(slices.Values(words), func(w string) bool { return len(w) > 2 })
	fmt.Println(slices.Collect(long))
	for i, w := range slices.Backward(words) {
		fmt.Print(i, ":", w, " ")
	}
	fmt.Println()
	fmt.Println(slices.Sorted(Filter(slices.Values(words), func(w string) bool { return w != "is" })))
}
```

Iterators are **lazy**: nothing runs until a loop asks for values, so a chain of filters over a huge (or infinite) sequence uses no extra memory.

package main

import (
	"fmt"
	"iter"
	"slices"
	"strings"
)

func Primes() iter.Seq[int] {
	return func(yield func(int) bool) {
		for n := 2; ; n++ {
			prime := true
			for d := 2; d*d <= n; d++ {
				if n%d == 0 {
					prime = false
					break
				}
			}
			if prime && !yield(n) {
				return
			}
		}
	}
}

func Lines(text string) iter.Seq2[int, string] {
	return func(yield func(int, string) bool) {
		for i, line := range strings.Split(text, "\n") {
			line = strings.TrimSpace(line)
			if line == "" {
				continue
			}
			if !yield(i+1, line) {
				return
			}
		}
	}
}

func Take[V any](seq iter.Seq[V], n int) iter.Seq[V] {
	return func(yield func(V) bool) {
		if n <= 0 {
			return
		}
		count := 0
		for v := range seq {
			if !yield(v) {
				return
			}
			count++
			if count == n {
				return
			}
		}
	}
}

func main() {
	text := "alpha\n\n  beta \ngamma\ndelta"
	for i, line := range Lines(text) {
		if line == "delta" {
			break
		}
		fmt.Printf("%d: %s\n", i, line)
	}
	fmt.Println("first 5 primes:", slices.Collect(Take(Primes(), 5)))
}

package main

import "fmt"

type Cents int

func (c Cents) String() string { return fmt.Sprintf("%d.%02d", c/100, c%100) }

type Rule interface {
	Apply(total Cents) (Cents, string)
}

type PercentOff struct {
	Percent  int
	MinTotal Cents
}

func (r PercentOff) Apply(total Cents) (Cents, string) {
	if total < r.MinTotal {
		return total, ""
	}
	return total - total*Cents(r.Percent)/100, fmt.Sprintf("%d%% off", r.Percent)
}

type FixedOff struct{ Amount Cents }

func (r FixedOff) Apply(total Cents) (Cents, string) {
	off := min(r.Amount, total)
	return total - off, "-" + off.String()
}

type FreeShipping struct{ Threshold, Fee Cents }

func (r FreeShipping) Apply(total Cents) (Cents, string) {
	if total < r.Threshold {
		return total + r.Fee, "shipping " + r.Fee.String()
	}
	return total, "free shipping"
}

func Checkout(total Cents, rules ...Rule) (Cents, []string) {
	var reasons []string
	for _, r := range rules {
		var why string
		total, why = r.Apply(total)
		if why != "" {
			reasons = append(reasons, why)
		}
	}
	return total, reasons
}

func main() {
	rules := []Rule{PercentOff{10, 5000}, FixedOff{400}, FreeShipping{Threshold: 5000, Fee: 495}}
	for _, cart := range []Cents{12000, 3000, 300} {
		total, reasons := Checkout(cart, rules...)
		fmt.Println("cart", cart, "->", total, reasons)
	}
}
