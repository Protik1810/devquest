=== lesson java-control | Decisions: if and switch | 60
## if, else if, else

```java
public class Main {
    public static void main(String[] args) {
        int score = 72;
        String grade;
        if (score >= 90) {
            grade = "A";
        } else if (score >= 75) {
            grade = "B";
        } else if (score >= 60) {
            grade = "C";
        } else {
            grade = "F";
        }
        System.out.println("Grade: " + grade);
    }
}
```

The condition must be a `boolean`: Java has no "truthy" values, so `if (count)` is a compile error (write `if (count > 0)`). Braces can be left out for a single statement, but always writing them avoids a classic bug when a second line is added later.

Notice that `grade` is declared without a value and assigned in every branch: the compiler checks that every path assigns it before use (remove the `else` and you get `variable grade might not have been initialized`).

## switch expressions (Java 14+)

When one value is compared against several constants, a **switch expression** is clearer than a chain of `if`s:

```java
public class Main {
    public static void main(String[] args) {
        String day = "SAT";
        int hours = switch (day) {
            case "MON", "TUE", "WED", "THU" -> 8;
            case "FRI" -> 6;
            case "SAT", "SUN" -> 0;
            default -> throw new IllegalArgumentException("Unknown day: " + day);
        };
        System.out.println(day + ": " + hours + " working hours");

        int month = 2;
        String season = switch (month) {
            case 12, 1, 2 -> "winter";
            case 3, 4, 5 -> "spring";
            case 6, 7, 8 -> "summer";
            case 9, 10, 11 -> "autumn";
            default -> "invalid";
        };
        System.out.println(season);
    }
}
```

- `case A, B ->` lists several values; the arrow form never "falls through".
- A switch **expression** produces a value and must be **exhaustive**: every possible input needs a case (hence `default`). With enums and sealed types (Module 4), the compiler can check exhaustiveness without a `default`.
- For a multi-line case, use a block and `yield`: `case "FRI" -> { log(); yield 6; }`.
- `switch` works on `int`, `char`, `String`, enums, and (Java 21) on any object with **pattern matching** (Module 6).

## The old switch statement

Existing code is full of the older form, with colons and `break`:

```java
public class Main {
    public static void main(String[] args) {
        int level = 2;
        switch (level) {
            case 1:
                System.out.println("beginner");
                break;
            case 2:
                System.out.println("intermediate");
                // no break: falls through into the next case!
            case 3:
                System.out.println("advanced");
                break;
            default:
                System.out.println("unknown");
        }
    }
}
```

Forgetting a `break` makes execution **fall through** into the next case (here, level 2 prints two lines). Prefer the arrow form in new code.

=== lesson java-loops | Loops | 60
## while and do-while

```java
public class Main {
    public static void main(String[] args) {
        int balance = 1000;
        int years = 0;
        while (balance < 2000) {
            balance += balance * 7 / 100;
            years++;
        }
        System.out.println("Doubled after " + years + " years: " + balance);

        int n = 0;
        do {
            System.out.print(n + " ");
            n += 3;
        } while (n < 10);
        System.out.println();
    }
}
```

`while` checks its condition **before** each round (it may run zero times); `do ... while` checks **after**, so it always runs at least once (useful for "ask until the answer is valid").

## for loops

The classic `for` has three parts: initialisation, condition, update:

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.print(i * i + " ");
        }
        System.out.println();
        for (int i = 10; i > 0; i -= 3) {
            System.out.print(i + " ");
        }
        System.out.println();
    }
}
```

The **enhanced for** (for-each) loops over every element of an array or collection, without an index:

```java
public class Main {
    public static void main(String[] args) {
        String[] planets = {"Mercury", "Venus", "Earth"};
        for (String planet : planets) {
            System.out.println(planet + " has " + planet.length() + " letters");
        }
    }
}
```

Use for-each whenever you don't need the index; it can't go out of bounds.

## break, continue and labels

```java
public class Main {
    public static void main(String[] args) {
        for (int n = 1; n <= 20; n++) {
            if (n % 2 == 0) continue;     // skip even numbers
            if (n > 9) break;             // stop the loop entirely
            System.out.print(n + " ");
        }
        System.out.println();

        outer:
        for (int row = 1; row <= 3; row++) {
            for (int col = 1; col <= 3; col++) {
                if (row * col == 4) break outer;   // leaves both loops
                System.out.print(row + "x" + col + " ");
            }
        }
        System.out.println();
    }
}
```

A **label** (`outer:`) lets `break` or `continue` act on an outer loop, which avoids flag variables in nested searches.

## Nested loops

```java
public class Main {
    public static void main(String[] args) {
        for (int row = 1; row <= 4; row++) {
            StringBuilder line = new StringBuilder();
            for (int col = 1; col <= 4; col++) {
                line.append(String.format("%4d", row * col));
            }
            System.out.println(line);
        }
    }
}
```

An infinite loop (`while (true)`) is fine when something inside ends it with `break` or `return`; an accidental one makes DevQuest stop the program after a timeout.

=== lesson java-methods | Methods | 70
## Defining and calling methods

A **method** is a named, reusable block of code with **parameters** and a **return type**:

```java
public class Main {
    static double circleArea(double radius) {
        return Math.PI * radius * radius;
    }

    static void printLine(String text, int width) {
        System.out.println("=".repeat(width));
        System.out.println(text);
        System.out.println("=".repeat(width));
    }

    public static void main(String[] args) {
        double area = circleArea(2.0);
        printLine(String.format("Area: %.2f", area), 12);
    }
}
```

- `static` methods belong to the class and are called by name (from another class: `Main.circleArea(2)`). Module 4 introduces instance methods, which belong to objects.
- The **return type** comes before the name; `void` means nothing is returned. Every path of a non-void method must `return` a value of that type.
- **Parameters** are typed; arguments must match (or widen to) those types.

Good methods are **short**, do **one thing**, and have a name that's a verb describing it (`calculateTotal`, `isValid`, `formatDate`).

## Arguments are passed by value

Java copies each argument's value into the parameter. For primitives, the method can't change the caller's variable. For objects, the copied value is a **reference**: the method can change the object it points to, but not make the caller's variable point elsewhere.

```java
public class Main {
    static void tryToChange(int number, int[] numbers, StringBuilder text) {
        number = 99;                 // changes the local copy only
        numbers[0] = 99;             // changes the array the caller also sees
        text.append(" world");       // changes the shared object
        text = new StringBuilder("replaced");   // the caller's variable is unaffected
    }

    public static void main(String[] args) {
        int n = 1;
        int[] arr = {1, 2};
        StringBuilder sb = new StringBuilder("hello");
        tryToChange(n, arr, sb);
        System.out.println(n + " " + arr[0] + " " + sb);
    }
}
```

## Overloading

Several methods can share a name if their **parameter lists differ**; the compiler picks the best match:

```java
public class Main {
    static int max(int a, int b) { return a > b ? a : b; }
    static int max(int a, int b, int c) { return max(max(a, b), c); }
    static double max(double a, double b) { return a > b ? a : b; }

    public static void main(String[] args) {
        System.out.println(max(3, 9) + " " + max(4, 1, 7) + " " + max(2.5, 1.5));
    }
}
```

## Varargs

`Type... name` accepts any number of arguments, received as an array:

```java
public class Main {
    static int sum(int... numbers) {
        int total = 0;
        for (int n : numbers) total += n;
        return total;
    }

    public static void main(String[] args) {
        System.out.println(sum() + " " + sum(5) + " " + sum(1, 2, 3, 4));
    }
}
```

## Recursion

A method can call itself. Every recursive method needs a **base case** that stops the recursion:

```java
public class Main {
    static long factorial(int n) {
        if (n <= 1) return 1;            // base case
        return n * factorial(n - 1);     // recursive case
    }

    static int fibonacci(int n) {
        return n < 2 ? n : fibonacci(n - 1) + fibonacci(n - 2);
    }

    public static void main(String[] args) {
        System.out.println(factorial(20) + " " + fibonacci(20));
    }
}
```

Each call uses space on the **call stack**; very deep recursion (tens of thousands of levels) throws `StackOverflowError`. Loops are usually better for simple repetition; recursion shines for trees, divide-and-conquer and backtracking (see the DSA track).

public class Main {
    static int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }

    static int lcm(int a, int b) {
        return a / gcd(a, b) * b;
    }

    static boolean isPrime(int n) {
        if (n < 2) return false;
        for (int d = 2; (long) d * d <= n; d++) {
            if (n % d == 0) return false;
        }
        return true;
    }

    static String primesUpTo(int limit) {
        StringBuilder sb = new StringBuilder();
        for (int n = 2; n <= limit; n++) {
            if (isPrime(n)) {
                if (sb.length() > 0) sb.append(' ');
                sb.append(n);
            }
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        System.out.println("gcd(84, 36) = " + gcd(84, 36));
        System.out.println("lcm(4, 6) = " + lcm(4, 6));
        System.out.println("isPrime(97) = " + isPrime(97));
        System.out.println("primes up to 30: " + primesUpTo(30));
    }
}

=== lesson java-arrays | Arrays | 65
## Fixed-size lists of values

An **array** holds a fixed number of values of one type:

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] scores = new int[4];           // four ints, all 0
        scores[0] = 90;
        scores[3] = 75;
        String[] names = {"Ada", "Grace", "Linus"};  // created with values

        System.out.println(scores.length + " " + names.length);
        System.out.println(names[1] + " " + scores[3]);
        System.out.println(Arrays.toString(scores));
    }
}
```

- Indexes run from `0` to `length - 1`; anything else throws `ArrayIndexOutOfBoundsException`.
- New arrays are filled with defaults: `0`, `0.0`, `false`, or `null` for objects.
- `length` is a field (no parentheses), unlike `String.length()`.
- Printing an array directly shows something like `[I@1b6d3586`; use `Arrays.toString`.

## The Arrays helper class

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] numbers = {42, 7, 19, 3, 25};
        int[] copy = Arrays.copyOf(numbers, numbers.length);
        Arrays.sort(copy);
        System.out.println(Arrays.toString(copy));
        System.out.println(Arrays.binarySearch(copy, 19));          // index in the sorted array
        System.out.println(Arrays.equals(numbers, copy));            // false: different order
        int[] filled = new int[5];
        Arrays.fill(filled, 7);
        System.out.println(Arrays.toString(filled));
        System.out.println(Arrays.stream(numbers).sum() + " " + Arrays.stream(numbers).max().getAsInt());
    }
}
```

Arrays are objects: `int[] b = a;` copies the **reference**, so both names refer to the same array. Use `Arrays.copyOf` or `clone()` for a real copy, and `Arrays.equals` to compare contents (`==` compares references).

## Multi-dimensional arrays

A 2D array is an array of arrays:

```java
public class Main {
    public static void main(String[] args) {
        int[][] grid = {
            {1, 2, 3},
            {4, 5, 6},
        };
        int total = 0;
        for (int[] row : grid) {
            for (int value : row) total += value;
        }
        System.out.println(grid.length + " rows, " + grid[0].length + " columns, total " + total);
        System.out.println(grid[1][2]);
    }
}
```

## Arrays and command-line arguments

`main(String[] args)` receives the program's command-line arguments: `java Main.java report 2026` gives `args = {"report", "2026"}`.

Arrays can't grow. When you need a list that changes size, use an `ArrayList` (Module 5); arrays remain the right tool for fixed-size data, grids, and performance-critical code.

        for (int i = 0; i < temps.length; i++) {
            sum += temps[i];
            if (temps[i] > temps[hottest]) hottest = i;
        }
        System.out.printf("Average: %.1f%n", (double) sum / temps.length);
        System.out.println("Hottest day: " + (hottest + 1));
        int[] sorted = Arrays.copyOf(temps, temps.length);
        Arrays.sort(sorted);
        System.out.println("Sorted: " + Arrays.toString(sorted));
        System.out.println("Original: " + Arrays.toString(temps));
    }
}

public class Main {
    static int[] findPair(boolean[][] hall) {
        for (int row = 0; row < hall.length; row++) {
            for (int seat = 0; seat + 1 < hall[row].length; seat++) {
                if (!hall[row][seat] && !hall[row][seat + 1]) return new int[] {row, seat};
            }
        }
        return null;
    }

    static int countFree(boolean[][] hall) {
        int free = 0;
        for (boolean[] row : hall) {
            for (boolean taken : row) {
                if (!taken) free++;
            }
        }
        return free;
    }

::solution
public class Main {
    static String encode(String s) {
        StringBuilder out = new StringBuilder();
        int i = 0;
        while (i < s.length()) {
            char c = s.charAt(i);
            int run = 0;
            while (i < s.length() && s.charAt(i) == c) {
                run++;
                i++;
            }
            out.append(run).append(c);
        }
        return out.toString();
    }

    static String decode(String s) {
        StringBuilder out = new StringBuilder();
        int count = 0;
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                count = count * 10 + (c - '0');
            } else {
                out.append(String.valueOf(c).repeat(count));
                count = 0;
            }
        }
        return out.toString();
    }

    public static void main(String[] args) {
        System.out.println(encode("aaabccdddd"));
        System.out.println(decode("3a1b2c4d"));
        String text = "xxxxxxxxxxxxy";
        System.out.println(encode(text));
        System.out.println(decode(encode(text)).equals(text));
    }
}

12x1y

::hints
- Encode: walk the string; for each character, count how long its run is.
- Decode: build the count digit by digit (`count * 10 + (c - '0')`), and on a letter append it `count` times.
