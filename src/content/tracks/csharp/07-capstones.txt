=== lesson cs-project | Capstone 1: a personal expense tracker | 400
This capstone builds a small but complete application in two steps, the way features grow in real codebases: first the **domain model and business rules**, then **import and reporting**. Step 2's starter contains step 1's solution, so you can continue even if step 1 gave you trouble.

## How a task like this is approached

1. **Model the domain** first: an `Expense` is a value (a record), a `Category` is a fixed set (an enum), and the `Ledger` holds changing state behind a small public API.
2. **Validate at the boundary:** the ledger refuses invalid expenses with exceptions, so the rest of the code can trust its data.
3. **Keep I/O separate from logic:** the CSV importer only parses lines and reports problems; the ledger decides what's valid; the report only reads. Each piece is easy to test on its own.
4. **Answer questions with LINQ** once the data is right.

The top-level statements are the specification: they call your classes, and the printed output must match exactly. Don't change them.
--- goals
- design a domain with an enum, a record and a class that protects its rules
- validate input with exceptions and report problems without stopping
- parse CSV safely with DateOnly, decimal and enum parsing in the invariant culture
- write reports with LINQ: grouping, sorting, percentages and distinct months

class Ledger
{
    private readonly List<Expense> _expenses = new();
    private readonly Dictionary<Category, decimal> _budgets = new();

    public IReadOnlyList<Expense> Expenses => _expenses;

    public void SetBudget(Category category, decimal monthly)
    {
        if (monthly <= 0) throw new ArgumentException("budget must be positive");
        _budgets[category] = monthly;
    }

    public decimal? BudgetFor(Category category) => _budgets.TryGetValue(category, out decimal b) ? b : null;

    public string? Add(Expense expense)
    {
        if (string.IsNullOrWhiteSpace(expense.Description)) throw new ArgumentException("description is required");
        if (expense.Amount <= 0) throw new ArgumentException($"amount must be positive: {expense.Amount}");
        _expenses.Add(expense);
        if (BudgetFor(expense.Category) is not decimal budget) return null;
        decimal spent = TotalFor(expense.Category, expense.Date.Year, expense.Date.Month);
        return spent > budget ? $"{expense.Category} over budget in {expense.Date:yyyy-MM} by {spent - budget:0.00}" : null;
    }

    public decimal Total(int year, int month) => InMonth(year, month).Sum(e => e.Amount);

    public decimal TotalFor(Category category, int year, int month) =>
        InMonth(year, month).Where(e => e.Category == category).Sum(e => e.Amount);

    private IEnumerable<Expense> InMonth(int year, int month) =>
        _expenses.Where(e => e.Date.Year == year && e.Date.Month == month);
}

static class CsvImport
{
    public static List<string> Into(Ledger ledger, string path)
    {
        var errors = new List<string>();
        int lineNumber = 0;
        foreach (string line in File.ReadLines(path))
        {
            lineNumber++;
            if (lineNumber == 1) continue;
            string[] f = line.Split(',');
            if (f.Length != 4) { errors.Add($"line {lineNumber}: expected 4 fields, found {f.Length}"); continue; }
            if (!DateOnly.TryParseExact(f[0], "yyyy-MM-dd", CultureInfo.InvariantCulture, DateTimeStyles.None, out DateOnly date))
            { errors.Add($"line {lineNumber}: invalid date {f[0]}"); continue; }
            if (!decimal.TryParse(f[2], NumberStyles.Number, CultureInfo.InvariantCulture, out decimal amount))
            { errors.Add($"line {lineNumber}: invalid amount {f[2]}"); continue; }
            if (!Enum.TryParse(f[3], out Category category) || !Enum.IsDefined(category))
            { errors.Add($"line {lineNumber}: unknown category {f[3]}"); continue; }
            try
            {
                ledger.Add(new Expense(date, f[1], amount, category));
            }
            catch (ArgumentException e)
            {
                errors.Add($"line {lineNumber}: {e.Message}");
            }
        }
        return errors;
    }
}

class Report(Ledger ledger)
{
    public IEnumerable<string> MonthSummary(int year, int month)
    {
        decimal total = ledger.Total(year, month);
        return ledger.Expenses
            .Where(e => e.Date.Year == year && e.Date.Month == month)
            .GroupBy(e => e.Category)
            .Select(g => (Category: g.Key, Sum: g.Sum(e => e.Amount)))
            .OrderByDescending(x => x.Sum)
            .Select(x => $"{x.Category,-9} {x.Sum,8:0.00} {x.Sum / total * 100,5:0.0}%")
            .Append($"{"Total",-9} {total,8:0.00}");
    }

    public decimal AverageDaily(int year, int month) => ledger.Total(year, month) / DateTime.DaysInMonth(year, month);

    public IEnumerable<Expense> TopExpenses(int n) =>
        ledger.Expenses.OrderByDescending(e => e.Amount).ThenBy(e => e.Date).Take(n);

    public IEnumerable<string> Recurring() =>
        ledger.Expenses
            .GroupBy(e => e.Description)
            .Where(g => g.Select(e => (e.Date.Year, e.Date.Month)).Distinct().Count() >= 2)
            .Select(g => g.Key)
            .Order();

    public DayOfWeek BusiestWeekday() =>
        ledger.Expenses
            .GroupBy(e => e.Date.DayOfWeek)
            .OrderByDescending(g => g.Sum(e => e.Amount))
            .First().Key;
}

=== lesson cs-capstone-async | Capstone 2: an async web crawler | 450
A **web crawler** starts at one page, follows its links, then their links, and so on: search engines, link checkers and archivers all work this way. It's the perfect async exercise: almost all the time goes into **waiting** for pages, broken links must not stop the crawl, and a slow server must not hang it.

The crawler talks to the web through an `IWebClient` interface. The given `FakeWeb` implements it with an in-memory set of pages and artificial delays, so the results are repeatable; a real version would wrap `HttpClient` and implement the same interface. That's dependency injection paying off: the crawler doesn't know or care which one it gets.

## The algorithm: breadth-first search

1. Start with the first page at depth 0, and remember it as **seen**.
2. Fetch a page, extract its links (`href="..."`), and record the result.
3. Every link not seen yet becomes a page to visit at **depth + 1**, unless the page is already at the maximum depth.
4. Continue until there's nothing left to visit.

The `seen` set guarantees each page is fetched once, even when pages link to each other in circles (`/blog/1` and `/blog/2` link to each other).

## From simple to fast and safe

Step 1 fetches one page at a time: simple but slow. Step 2 fetches each depth level **concurrently**, but politely: at most `maxConcurrency` requests at once (a `SemaphoreSlim`), and each request gets a **timeout** (a `CancellationTokenSource`), so one slow server can't stall everything.
--- goals
- implement breadth-first search over a graph with a queue and a seen set
- depend on an interface so the network can be faked
- run requests concurrently with Task.WhenAll while limiting concurrency with SemaphoreSlim
- give every request a timeout with CancellationTokenSource, and classify failures

class Crawler(IWebClient web)
{
    private static readonly Regex LinkPattern = new("href=\"([^\"]+)\"");

    public async Task<List<PageResult>> CrawlAsync(string start, int maxDepth)
    {
        var results = new List<PageResult>();
        var seen = new HashSet<string> { start };
        var queue = new Queue<(string Url, int Depth)>();
        queue.Enqueue((start, 0));
        while (queue.Count > 0)
        {
            var (url, depth) = queue.Dequeue();
            try
            {
                string html = await web.GetAsync(url, CancellationToken.None);
                List<string> links = LinkPattern.Matches(html).Select(m => m.Groups[1].Value).Distinct().ToList();
                results.Add(new PageResult(url, depth, "ok", links.Count));
                if (depth < maxDepth)
                {
                    foreach (string link in links)
                        if (seen.Add(link)) queue.Enqueue((link, depth + 1));
                }
            }
            catch (HttpRequestException)
            {
                results.Add(new PageResult(url, depth, "broken", 0));
            }
        }
        return results.OrderBy(r => r.Depth).ThenBy(r => r.Url, StringComparer.Ordinal).ToList();
    }
}

class Crawler(IWebClient web, int maxConcurrency, TimeSpan timeout)
{
    private static readonly Regex LinkPattern = new("href=\"([^\"]+)\"");

    public async Task<List<PageResult>> CrawlAsync(string start, int maxDepth)
    {
        var results = new List<PageResult>();
        var seen = new HashSet<string> { start };
        var level = new List<string> { start };
        using var gate = new SemaphoreSlim(maxConcurrency);
        for (int depth = 0; level.Count > 0 && depth <= maxDepth; depth++)
        {
            int d = depth;
            var fetched = await Task.WhenAll(level.Select(url => FetchAsync(url, d, gate)));
            results.AddRange(fetched.Select(f => f.Result));
            level = fetched
                .SelectMany(f => f.Links)
                .Where(seen.Add)
                .ToList();
        }
        return results.OrderBy(r => r.Depth).ThenBy(r => r.Url, StringComparer.Ordinal).ToList();
    }

    private async Task<(PageResult Result, List<string> Links)> FetchAsync(string url, int depth, SemaphoreSlim gate)
    {
        await gate.WaitAsync();
        try
        {
            using var cts = new CancellationTokenSource(timeout);
            string html = await web.GetAsync(url, cts.Token);
            List<string> links = LinkPattern.Matches(html).Select(m => m.Groups[1].Value).Distinct().ToList();
            return (new PageResult(url, depth, "ok", links.Count), links);
        }
        catch (HttpRequestException)
        {
            return (new PageResult(url, depth, "broken", 0), new List<string>());
        }
        catch (OperationCanceledException)
        {
            return (new PageResult(url, depth, "timeout", 0), new List<string>());
        }
        finally
        {
            gate.Release();
        }
    }
}

=== lesson cs-capstone-solo | Capstone 3: build it from a spec | 450
The final capstone gives you a **specification** and a test harness, and nothing else: you design and write the types from scratch. The domain is a classic: **hotel bookings**, with dates, overlaps, pricing rules and cancellation fees.

## The specification

**Types** (names and members are fixed by the harness):

- `enum RoomType { Single, Double, Suite }`;
- `record Room(int Number, RoomType Type, decimal NightlyRate)`;
- `record Booking(int Id, int RoomNumber, string Guest, DateOnly CheckIn, DateOnly CheckOut, decimal Price)` with a computed `int Nights`;
- `class BookingException` (an `Exception` with a message);
- `class Hotel` with the methods below.

**Rules:**

1. `AddRoom(room)` refuses a number that already exists: `room <n> already exists`.
2. `Book(roomNumber, guest, checkIn, checkOut)` checks, in this order: unknown room → `unknown room <n>`; check-out not after check-in → `check-out must be after check-in`; more than 14 nights → `stays are limited to 14 nights`; the room is taken for any of those nights → `room <n> is not available from <yyyy-MM-dd> to <yyyy-MM-dd>` (the requested dates). Two stays overlap when each starts before the other ends, so one guest can check in on the day another checks out.
3. **Price:** each night costs the room's rate, Friday and Saturday nights cost 25% more, stays of 7 nights or more get 10% off the total; round to 2 decimals (away from zero). Booking ids start at 1 and count up.
4. `FindAvailable(type, checkIn, checkOut)` returns the numbers of free rooms of that type, ascending.
5. `Cancel(bookingId, today)`: unknown id → `unknown booking <id>`; less than 1 day before check-in → `too late to cancel booking <id>`; otherwise removes the booking and returns the fee: nothing 7 or more days before check-in, half the price (rounded to 2 decimals) otherwise.
6. `Occupancy(from, to)` returns the percentage of room-nights booked between `from` (included) and `to` (excluded) across all rooms, rounded to 1 decimal.
7. `GuestReport()` returns one line per guest, in alphabetical order: `Ada: 2 bookings, 11 nights, 2328.75` (`1 booking` in the singular).

## How to approach it

1. Write the types and method signatures first, with placeholder bodies, so the harness compiles.
2. `DateOnly` is ideal for dates without times: compare with `<`, step with `AddDays(1)`, and count nights with `DayNumber` differences.
3. Write the overlap test once (a method on `Booking`) and reuse it in `Book` and `FindAvailable`.
4. For occupancy, clip each booking to the period: the overlap of `[CheckIn, CheckOut)` and `[from, to)`.
5. Run the harness and compare the output line by line.
--- goals
- design a set of types from a written specification
- work with dates using DateOnly: ranges, overlaps and weekdays
- implement pricing and fee rules exactly, with decimal rounding
- keep refused operations free of side effects

static void Try(string label, Action action)
{
    try
    {
        action();
        Console.WriteLine($"{label}: no error");
    }
    catch (BookingException e)
    {
        Console.WriteLine($"{label}: {e.Message}");
    }
}

enum RoomType { Single, Double, Suite }

record Room(int Number, RoomType Type, decimal NightlyRate);

record Booking(int Id, int RoomNumber, string Guest, DateOnly CheckIn, DateOnly CheckOut, decimal Price)
{
    public int Nights => CheckOut.DayNumber - CheckIn.DayNumber;
    public bool Overlaps(DateOnly from, DateOnly to) => CheckIn < to && from < CheckOut;
}

class BookingException(string message) : Exception(message) { }

class Hotel
{
    private readonly SortedDictionary<int, Room> _rooms = new();
    private readonly Dictionary<int, Booking> _bookings = new();
    private int _nextId = 1;

    public void AddRoom(Room room)
    {
        if (!_rooms.TryAdd(room.Number, room)) throw new BookingException($"room {room.Number} already exists");
    }

    public Booking Book(int roomNumber, string guest, DateOnly checkIn, DateOnly checkOut)
    {
        if (!_rooms.TryGetValue(roomNumber, out Room? room)) throw new BookingException($"unknown room {roomNumber}");
        if (checkOut <= checkIn) throw new BookingException("check-out must be after check-in");
        if (checkOut.DayNumber - checkIn.DayNumber > 14) throw new BookingException("stays are limited to 14 nights");
        if (!IsFree(roomNumber, checkIn, checkOut))
            throw new BookingException($"room {roomNumber} is not available from {checkIn:yyyy-MM-dd} to {checkOut:yyyy-MM-dd}");
        var booking = new Booking(_nextId++, roomNumber, guest, checkIn, checkOut, Price(room, checkIn, checkOut));
        _bookings[booking.Id] = booking;
        return booking;
    }

    public IEnumerable<int> FindAvailable(RoomType type, DateOnly checkIn, DateOnly checkOut) =>
        _rooms.Values.Where(r => r.Type == type && IsFree(r.Number, checkIn, checkOut)).Select(r => r.Number);

    public decimal Cancel(int bookingId, DateOnly today)
    {
        if (!_bookings.TryGetValue(bookingId, out Booking? booking)) throw new BookingException($"unknown booking {bookingId}");
        int daysBefore = booking.CheckIn.DayNumber - today.DayNumber;
        if (daysBefore < 1) throw new BookingException($"too late to cancel booking {bookingId}");
        _bookings.Remove(bookingId);
        return daysBefore >= 7 ? 0m : Math.Round(booking.Price / 2, 2, MidpointRounding.AwayFromZero);
    }

    public decimal Occupancy(DateOnly from, DateOnly to)
    {
        int nights = to.DayNumber - from.DayNumber;
        int booked = 0;
        foreach (Booking b in _bookings.Values)
        {
            int start = Math.Max(b.CheckIn.DayNumber, from.DayNumber);
            int end = Math.Min(b.CheckOut.DayNumber, to.DayNumber);
            if (end > start) booked += end - start;
        }
        return Math.Round(100m * booked / (nights * _rooms.Count), 1, MidpointRounding.AwayFromZero);
    }

    public IEnumerable<string> GuestReport() =>
        _bookings.Values
            .GroupBy(b => b.Guest)
            .OrderBy(g => g.Key, StringComparer.Ordinal)
            .Select(g => $"{g.Key}: {g.Count()} booking{(g.Count() == 1 ? "" : "s")}, {g.Sum(b => b.Nights)} nights, {g.Sum(b => b.Price):0.00}");

    private bool IsFree(int roomNumber, DateOnly checkIn, DateOnly checkOut) =>
        !_bookings.Values.Any(b => b.RoomNumber == roomNumber && b.Overlaps(checkIn, checkOut));

    private static decimal Price(Room room, DateOnly checkIn, DateOnly checkOut)
    {
        decimal total = 0;
        for (DateOnly night = checkIn; night < checkOut; night = night.AddDays(1))
        {
            bool weekend = night.DayOfWeek is DayOfWeek.Friday or DayOfWeek.Saturday;
            total += weekend ? room.NightlyRate * 1.25m : room.NightlyRate;
        }
        if (checkOut.DayNumber - checkIn.DayNumber >= 7) total *= 0.9m;
        return Math.Round(total, 2, MidpointRounding.AwayFromZero);
    }
}

=== lesson cs-whats-next | What's next after C# | 50
## You've learned C#

You can now write and run C# programs, use its type system precisely (value and reference types, nullable references, decimal), structure code with methods, classes, structs, records and interfaces, handle errors with exceptions and `using`, work with collections, generics, delegates, events and LINQ, write async and parallel code safely, read and write files and JSON, organise projects with namespaces and NuGet, use attributes and reflection, test your code, and explain how ASP.NET Core APIs work. That's the foundation every professional .NET developer builds on.

## Where to go from here

- **Web back ends:** ASP.NET Core with minimal APIs or controllers, Entity Framework Core with PostgreSQL or SQL Server (the SQL course helps), authentication, OpenAPI and Docker. Microsoft Learn's ASP.NET Core learning path is excellent and free.
- **Games:** **Unity** uses C# for game logic (MonoBehaviour scripts, coroutines, the component model); **Godot** supports C# too.
- **Desktop and mobile:** **.NET MAUI** (Windows, macOS, Android and iOS from one code base), **WPF** and **WinForms** for Windows tools, and **Avalonia** for cross-platform desktop apps.
- **Cloud and services:** Azure Functions, worker services, gRPC, and **.NET Aspire** for distributed applications.
- **Deepen your C#:** Jon Skeet's *C# in Depth*, Joseph Albahari's *C# in a Nutshell*, and the "What's new in C#" pages for each release (records, pattern matching and primary constructors all arrived recently). *Programming C#* (Jesse Liberty) shows where the language started, in C# 1.0.
- **Other languages:** DevQuest teaches one language at a time. Next in the order is **Go**: a smaller language with a very different style (no classes, explicit errors, goroutines and channels), which will sharpen how you think about simplicity and concurrency.

## Keep your skills alive

- Build something end to end: a small web API with EF Core and tests, deployed in a container.
- Turn on analyzers (`<AnalysisLevel>latest-recommended</AnalysisLevel>`) and treat warnings as errors; they teach idioms.
- Read good code: the .NET runtime itself (github.com/dotnet/runtime) is open source.
- Practise on Exercism's C# track, Advent of Code, or the DSA track in DevQuest.
