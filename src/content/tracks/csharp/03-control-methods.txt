## if and else

```csharp
int score = 72;
string grade;
if (score >= 90)
{
    grade = "A";
}
else if (score >= 75)
{
    grade = "B";
}
else if (score >= 60)
{
    grade = "C";
}
else
{
    grade = "F";
}
Console.WriteLine($"Grade: {grade}");
```

Conditions must be `bool` (no "truthy" values), and the compiler checks that `grade` is assigned on every path before it's used (error CS0165 otherwise).

## switch expressions

A **switch expression** maps a value to a result, with **patterns** for each case:

```csharp
string Season(int month) => month switch
{
    12 or 1 or 2 => "winter",
    >= 3 and <= 5 => "spring",
    >= 6 and <= 8 => "summer",
    >= 9 and <= 11 => "autumn",
    _ => throw new ArgumentOutOfRangeException(nameof(month)),
};

decimal Shipping(string zone, decimal weightKg) => (zone, weightKg) switch
{
    ("domestic", <= 2) => 4.00m,
    ("domestic", _) => 6.50m,
    ("europe", _) => 9.50m + weightKg,
    _ => 25m,
};

Console.WriteLine(Season(2) + " " + Season(7));
Console.WriteLine($"{Shipping("domestic", 1.5m)} {Shipping("domestic", 3m)} {Shipping("europe", 2m)} {Shipping("mars", 1m)}");
```

- Each arm is `pattern => result`; the first matching arm wins.
- `_` is the **discard** pattern: "anything else".
- Patterns can be constants, relational (`>= 3`), combined (`and`, `or`, `not`), **tuples** of several values (`(zone, weight)`), types (`int n`) and properties (Module 4).
- If no arm matches, a `SwitchExpressionException` is thrown, and the compiler warns when it can see cases are missing.

## The switch statement

The statement form runs code for each case. Unlike C and Java, C# **forbids fall-through**: every non-empty section must end with `break`, `return` or `throw`:

```csharp
int level = 2;
switch (level)
{
    case 1:
        Console.WriteLine("beginner");
        break;
    case 2:
    case 3:
        Console.WriteLine("intermediate or advanced");
        break;
    default:
        Console.WriteLine("unknown");
        break;
}
```

Empty cases can be stacked (`case 2: case 3:`). Prefer switch expressions when computing a value.

=== lesson cs-loops | Loops | 55
## while, do-while, for and foreach

```csharp
int balance = 1000, years = 0;
while (balance < 2000)
{
    balance += balance * 7 / 100;
    years++;
}
Console.WriteLine($"Doubled after {years} years: {balance}");

int n = 0;
do
{
    Console.Write(n + " ");
    n += 3;
} while (n < 10);
Console.WriteLine();

for (int i = 1; i <= 5; i++) Console.Write(i * i + " ");
Console.WriteLine();

string[] planets = { "Mercury", "Venus", "Earth" };
foreach (string planet in planets) Console.WriteLine($"{planet} has {planet.Length} letters");
```

- `while` checks before each round; `do ... while` after (at least one round).
- `for (init; condition; update)` for counting loops.
- **`foreach`** iterates over any collection (arrays, lists, strings, dictionaries, LINQ queries); the loop variable is read-only.

## break, continue and nested loops

```csharp
for (int i = 1; i <= 20; i++)
{
    if (i % 2 == 0) continue;
    if (i > 9) break;
    Console.Write(i + " ");
}
Console.WriteLine();

bool found = false;
for (int row = 1; row <= 3 && !found; row++)
{
    for (int col = 1; col <= 3; col++)
    {
        if (row * col == 4) { found = true; break; }
        Console.Write($"{row}x{col} ");
    }
}
Console.WriteLine();
```

C# has no labelled `break`; leave nested loops with a flag (as above), by moving them into a method and using `return`, or (rarely) with `goto`.

## Ranges of numbers

```csharp
Console.WriteLine(Enumerable.Range(1, 100).Sum());
```

=== lesson cs-methods | Methods, parameters and local functions | 70
## Defining methods

```csharp
Console.WriteLine(CircleArea(2).ToString("F2"));
Console.WriteLine(Describe("Ada"));
Console.WriteLine(Describe("Grace", 45));
Console.WriteLine(Describe(age: 30, name: "Linus"));      // named arguments, any order
Console.WriteLine(Sum(1, 2, 3, 4));

static double CircleArea(double radius) => Math.PI * radius * radius;

static string Describe(string name, int age = -1)          // optional parameter with a default
    => age < 0 ? name : $"{name} ({age})";

static int Sum(params int[] numbers)                       // any number of arguments
{
    int total = 0;
    foreach (int n in numbers) total += n;
    return total;
}
```

- **Optional parameters** have defaults; **named arguments** make calls readable (`Describe(age: 30, name: "Linus")`).
- **`params`** accepts any number of arguments as an array (like Java's varargs).
- **Overloading**: several methods may share a name if their parameters differ.
- In a file with top-level statements, methods declared at the top level are **local functions** of the generated `Main`; `static` ones can't accidentally capture local variables.

## ref, out and in

By default arguments are passed **by value** (for reference types, the reference is copied, as in Java). C# also lets a method work on the **caller's variable** itself:

```csharp
int a = 1, b = 2;
Swap(ref a, ref b);
Console.WriteLine($"{a} {b}");

if (TryDivide(10, 4, out double result)) Console.WriteLine(result);
if (!TryDivide(1, 0, out _)) Console.WriteLine("cannot divide by zero");

static void Swap(ref int x, ref int y) => (x, y) = (y, x);

static bool TryDivide(double x, double y, out double quotient)
{
    if (y == 0) { quotient = 0; return false; }
    quotient = x / y;
    return true;
}
```

- **`ref`**: the method reads and can change the caller's variable;
- **`out`**: the method **must** assign it (the "Try" pattern: `int.TryParse(s, out int n)`); `out _` discards a value you don't need;
- **`in`**: passed by reference but read-only (an optimisation for large structs).

`(x, y) = (y, x)` swaps with **tuples**, which also let a method return several values: `static (int min, int max) Range(int[] xs)`.

## Tuples for multiple results

```csharp
var (min, max) = MinMax(new[] { 4, 9, 1, 7 });
Console.WriteLine($"{min} {max}");
var stats = MinMax(new[] { 3, 3 });
Console.WriteLine($"{stats.Min}..{stats.Max}");

static (int Min, int Max) MinMax(int[] values)
{
    int min = int.MaxValue, max = int.MinValue;
    foreach (int v in values) { min = Math.Min(min, v); max = Math.Max(max, v); }
    return (min, max);
}
```

## Recursion

```csharp
Console.WriteLine($"{Factorial(20)} {Fibonacci(20)}");

static long Factorial(int n) => n <= 1 ? 1 : n * Factorial(n - 1);
static int Fibonacci(int n) => n < 2 ? n : Fibonacci(n - 1) + Fibonacci(n - 2);
```

Every recursive method needs a base case; very deep recursion throws `StackOverflowException`, which (unlike other exceptions) can't be caught and ends the process.

static int Gcd(int a, int b) => b == 0 ? a : Gcd(b, a % b);

static int Lcm(int a, int b) => a / Gcd(a, b) * b;

static bool IsPrime(int n)
{
    if (n < 2) return false;
    for (int d = 2; (long)d * d <= n; d++)
    {
        if (n % d == 0) return false;
    }
    return true;
}

static string PrimesUpTo(int limit)
{
    var primes = new List<int>();
    for (int n = 2; n <= limit; n++)
    {
        if (IsPrime(n)) primes.Add(n);
    }
    return string.Join(" ", primes);
}

static (int Min, int Max) MinMax(params int[] values)
{
    int min = int.MaxValue, max = int.MinValue;
    foreach (int v in values)
    {
        min = Math.Min(min, v);
        max = Math.Max(max, v);
    }
    return (min, max);
}

=== lesson cs-arrays | Arrays, indexes and ranges | 60
## Arrays

```csharp
int[] scores = new int[4];             // four ints, all 0
scores[0] = 90;
scores[^1] = 75;                       // ^1 = the last element
string[] names = { "Ada", "Grace", "Linus" };
int[] primes = [2, 3, 5, 7];           // collection expression (C# 12)

Console.WriteLine($"{scores.Length} {names[1]} {scores[^1]}");
Console.WriteLine(string.Join(", ", scores));
Console.WriteLine(string.Join(", ", primes[1..3]));    // a range: elements 1 and 2
```

- Indexes run from `0` to `Length - 1`; `^1` is the last element, `^2` the one before.
- **Ranges** `a[start..end]` copy a slice (end-exclusive); `a[..2]` and `a[2..]` leave out one side.
- Arrays are reference types: `int[] b = a;` shares the array; `(int[])a.Clone()` or `a[..]` copies it.
- New arrays are filled with defaults (`0`, `false`, `null`).

## The Array class

```csharp
int[] numbers = { 42, 7, 19, 3, 25 };
int[] sorted = (int[])numbers.Clone();
Array.Sort(sorted);
Console.WriteLine(string.Join(" ", sorted));
Console.WriteLine(Array.IndexOf(numbers, 19) + " " + Array.BinarySearch(sorted, 19));
Array.Reverse(sorted);
Console.WriteLine(string.Join(" ", sorted));
Console.WriteLine($"{numbers.Max()} {numbers.Sum()} {numbers.Average()}");   // LINQ, Module 5
Console.WriteLine(Array.Exists(numbers, n => n > 40));
```

## Multi-dimensional and jagged arrays

C# has **rectangular** arrays (`int[,]`, one block of rows × columns) and **jagged** arrays (`int[][]`, arrays of arrays whose rows can differ in length):

```csharp
int[,] grid = { { 1, 2, 3 }, { 4, 5, 6 } };
Console.WriteLine($"{grid.GetLength(0)} rows, {grid.GetLength(1)} columns, middle {grid[1, 1]}");

int[][] triangle = new int[4][];
for (int r = 0; r < triangle.Length; r++)
{
    triangle[r] = new int[r + 1];
    triangle[r][0] = triangle[r][r] = 1;
    for (int c = 1; c < r; c++) triangle[r][c] = triangle[r - 1][c - 1] + triangle[r - 1][c];
}
foreach (int[] row in triangle) Console.WriteLine(string.Join(" ", row));
```

## Span: views without copying

`Span<T>` (and the read-only `ReadOnlySpan<T>`) is a **view** over part of an array or string, without copying it. It's how high-performance .NET code (parsers, servers) avoids allocations:

```csharp
int[] data = { 1, 2, 3, 4, 5, 6 };
Span<int> middle = data.AsSpan(2, 3);   // a window over elements 2, 3, 4
middle[0] = 99;                         // writes into data
Console.WriteLine(string.Join(" ", data));
```

You'll mostly use spans indirectly (many library methods accept them); it's useful to know they exist.

Arrays have a fixed size; for collections that grow, use `List<T>` (Module 5).

::solution
using System.Text;

Console.WriteLine(Encode("aaabccdddd"));
Console.WriteLine(Decode("3a1b2c4d"));
string text = "xxxxxxxxxxxxy";
Console.WriteLine(Encode(text));
Console.WriteLine(Decode(Encode(text)) == text);

static string Encode(string s)
{
    var sb = new StringBuilder();
    int i = 0;
    while (i < s.Length)
    {
        char c = s[i];
        int run = 0;
        while (i < s.Length && s[i] == c) { run++; i++; }
        sb.Append(run).Append(c);
    }
    return sb.ToString();
}

static string Decode(string s)
{
    var sb = new StringBuilder();
    int count = 0;
    foreach (char c in s)
    {
        if (char.IsDigit(c)) count = count * 10 + (c - '0');
        else
        {
            sb.Append(c, count);
            count = 0;
        }
    }
    return sb.ToString();
}

::hints
- Encode: for each character, count its run, then append count and character.
- Decode: build the count digit by digit; `sb.Append(c, count)` appends a character `count` times.
